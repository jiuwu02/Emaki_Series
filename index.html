Emaki SeriesPaper RPG 插件套件

面向 Paper 1.21.8+ 与 Java 25 的 RPG 插件套件。按模块安装，按 YAML 配置，按 CoreLib 统一动作、GUI、物品来源和 PDC 数据。

快速开始
架构总览

  • 先确认 CoreLib

    所有业务模块都依赖 CoreLib。先理解动作、GUI、物品来源、PDC、表达式和经济桥接，再改业务配置。

  • 属性先落到 PDC

    Attribute 负责属性定义、资源、伤害类型和条件。装备属性建议写入 PDC，不要只依赖 Lore 文本。

  • 装备按层叠加

    Item、Forge、Strengthen、Gem 分别写入基础物品、锻造层、强化层和宝石层，Accessory 提供独立饰品栏，CoreLib 负责重建展示。

  • 成长与生产分开读

    Level 管多类型经验；Skills 管触发、冷却和资源消耗；Station 管通用合成与队列；Cooking 管世界工位和坐标状态。

Emaki Series 文档 ​

Emaki Series 是一组可组合安装的 Paper RPG 插件。它把物品、属性、成长、技能、图鉴、世界工位和自定义生物拆成独立模块，用 CoreLib 统一动作、GUI、物品来源、PDC 和展示重建。当前源码按 14 组 runtime/API 模块组织；你可以只启用需要的模块，也可以组合成完整 RPG 玩法链。

推荐阅读路径 ​

  1. 先读 项目介绍，确认要安装哪些模块。
  2. 再读 快速开始，完成构建、安装和首次启动。
  3. 写 YAML 前，先读 CoreLib 的物品来源、动作、条件、表达式和 GUI。
  4. 做装备成长时，按 Attribute → Item → Forge / Strengthen / Gem / Accessory 的顺序阅读。
  5. 做成长与玩法系统时，分别阅读 Level、Skills、Station、Cooking、Codex 与 Storage。它们解决的问题不同。
  6. 做二次开发时，重点看 CoreLib 的 PDC、Assembly，以及各业务模块自己的 API（如 emaki-attribute-api、emaki-item-api、emaki-level-api）。

模块总览 ​

模块角色适合解决的问题
EmakiCoreLib公共基础设施先读这里：动作、GUI、物品来源、PDC、表达式、经济、结构化展示。
EmakiAttribute属性与战斗定义属性、资源、伤害类型和条件，并给其他模块提供属性 API。
EmakiItem自定义物品生成稳定物品 ID，提供物品包/物品浏览 GUI，并写入基础属性、技能、套装和触发器。
EmakiForge锻造用图纸和材料改造装备或生成新装备，计算品质和材料贡献。
EmakiStrengthen强化按星级处理成功率、材料、失败惩罚、保护材料和强化展示。
EmakiGem宝石管理插槽、开孔、镶嵌、提取、升级和宝石共鸣。
EmakiAccessory饰品栏提供多页隔离的饰品槽位、启用页切换、孤儿槽取回、属性/技能贡献和饰品套装。
EmakiLevel等级成长管理多等级类型、经验来源、升级需求、PDC、Placeholder 和 MythicMobs 经验 Drop。
EmakiSkills技能管理主动/被动触发、冷却、资源消耗和 MythicMobs 调用。
EmakiStation合成工作站三页式通用合成站，串行队列、背包与仓库合并取材、付费队列位，并含独立的物品分解站。
EmakiCooking烹饪工位管理砧板、炒锅、研磨机、蒸锅、烤炉、榨汁机和发酵桶。
EmakiCodex图鉴与成就同时定义原版成就页与分类条目图鉴 GUI，支持解锁、激活、领取、奖励、命令、CoreLib 动作和 API。
EmakiStorageGUI 仓库单槽存放 long 量级数量并完整保留原始物品，容量由配置、权限、命令授予与付费扩容四来源决定，支持搜索与排序。
EmakiMobs自定义生物定义生物、刷新规则、掉落表和技能行为，并接入属性、技能与物品模块。
