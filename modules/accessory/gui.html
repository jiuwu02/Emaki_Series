页面导航

界面模板 ​

饰品栏界面由 plugins/EmakiAccessory/gui/accessory_gui.yml 描述。

槽位必须显式写 type ​

饰品格必须显式写 type: "accessory_slot"，不写 type 的格子只是纯装饰。

可用类型 ​

type作用
accessory_slot饰品格。键名必须等于槽位实例 id。
orphan_slot孤儿格，展示该页不再声明的槽位里的饰品供玩家取回。
page_enable启用格。点击把当前页设为生效页；只有生效页的饰品产生效果。
page_switch切页格。键名必须等于目标页的 page_id，点击切换到该页。

一个布局可以被多页共用：pages/*.yml 的 gui_template 指向布局 id。共用时要注意布局里摆放的槽位实例必须被该页的 parts 声明，否则该格对这一页不可用。

accessory_slot ​

键名必须等于槽位实例 id，格式为 <部位id>_<序号>，序号从 1 开始，与 parts.yml 里该部位的 count 对应。

例如 ring 部位 count: 2 就要摆放 ring_1 和 ring_2 两格：

yaml
slots:
  ring_1:
    slots: [12]
    type: "accessory_slot"
    item:
      source: "LIGHT_GRAY_STAINED_GLASS_PANE"
      components:
        custom_name: "<gray>戒指</gray>"
        lore:
          - "<dark_gray>放入饰品以生效</dark_gray>"
  ring_2:
    slots: [13]
    type: "accessory_slot"

每个 accessory_slot 只能占一格。写成多格时只有第一格生效，其余会记录警告。

parts.yml 里声明了但这里没摆放的槽位同样会记录警告，且玩家无法使用该槽位。

槽位的 item 段定义空槽时显示的占位物品，放入饰品后由真实物品替换。

orphan_slot ​

该页不再声明的槽位里的饰品会显示在这里供玩家取回，取走后不能再放回。缩减 parts.yml 的 count、删除部位，或把部位从某页的 parts 移除，都会产生孤儿。

yaml
slots:
  orphan:
    slots: "37-43"
    type: "orphan_slot"
    item:
      source: "GRAY_STAINED_GLASS_PANE"
      components:
        custom_name: "<gray>"
        tooltip_display:
          hide_tooltip: true

孤儿格可以占多格。判定按「所属页是否声明该槽位」，因此其他页的饰品不会被当成孤儿。

不摆放孤儿格也不会丢东西：数据仍在文件里，但玩家没有界面取回入口，只能靠 /eacc retrieve <页> 或改回配置。

page_enable ​

点击把当前打开的页设为生效页。只有生效页的饰品提供属性、技能与套装件数，其余页保留数据但不生效。

yaml
slots:
  page_enable:
    slots: [8]
    type: "page_enable"
    item:
      source: "lime_dye"

page_switch ​

键名必须等于目标页的 page_id，点击切换到该页。切页只是换界面，不改变生效页；要让新页生效仍需点 page_enable。

yaml
slots:
  main:
    slots: [0]
    type: "page_switch"
    item:
      source: "gold_ingot"
  secondary:
    slots: [1]
    type: "page_switch"
    item:
      source: "iron_ingot"

目标页设了 permission 且玩家没有该权限时，切页会被拒绝。

装饰格 ​

不写 type 的格子是纯装饰，例如边框：

yaml
slots:
  frame:
    slots: "0-8,45-53"
    item:
      source: "BLACK_STAINED_GLASS_PANE"
      components:
        custom_name: "<gray>"
        tooltip_display:
          hide_tooltip: true

点击行为 ​

格子点击一律被取消（不交给原版处理），随后按 type 分派：

操作结果
放入饰品先按槽位声明判据检查，不匹配提示 gui.slot_mismatch；再按 unique 查同页重复，重复提示 gui.unique_conflict。
取出饰品光标为空时点击格内饰品即取出。
双击、数字键、换手、丢弃、Ctrl+丢弃不支持，提示 gui.click_unsupported。
玩家背包侧的快捷搬运不支持，提示 gui.transfer_unsupported，请逐格放取。
只读窗口内的任何修改被拒绝，提示 gui.read_only。
向孤儿格放入物品被拒绝，提示 gui.orphan_read_only。
点击已生效页的 page_enable提示 gui.page_already_enabled，不改变状态。
点击当前页自身的 page_switch无动作；目标页不存在提示 gui.page_unknown，无权限提示 gui.page_no_permission。

切页会先关闭当前窗口，下一 tick 再打开目标页；切换过程中不会触发关闭时的落盘与租约释放，因此数据会话保持连续。

孤儿格按槽位 id 升序逐格填充，格子数量少于孤儿数量时超出的部分只能在 /eacc retrieve <页> 里取回。

顶层键 ​

字段类型必填默认值取值范围说明
idstring是——模板 id，供 pages/*.yml 的 gui_template 引用；为空时该模板不加载，引用它的页打不开（记录 accessory.gui_template_missing）。
gui_typestring否CHESTBukkit InventoryType 名（不区分大小写），非法值回退 CHEST界面类型。
titlestring否"GUI"—界面标题，支持 MiniMessage；也可写成文本配置节（CoreLib 文本格式）。
rowsinteger否31~6，超出范围被钳制行数；仅对支持自定义行数的类型（如 CHEST）生效。
slotsmap<string, object>否{}—槽位定义，键名即格子标识。

槽位键 ​

slots.<键名> 的键名在不同类型下有不同含义（见上文「可用类型」）。嵌套字段：

字段类型必填默认值取值范围说明
slots.<键名>.slotsinteger / list / string是—单格号、格号列表、或 "1-3,5" 形式的范围串；解析为空时该格被忽略该格占用的容器格号，从 0 开始。
slots.<键名>.typestring否空accessory_slot / orphan_slot / page_enable / page_switch格子行为；留空即纯装饰。accessory_slot 与 page_switch 依赖键名，见上文。
slots.<键名>.itemobject / string否空—该格渲染的物品定义；也可直接写物品来源字符串。
slots.<键名>.item.sourcestring否空—物品来源（原版材质名或 EmakiItem 定义等 CoreLib 物品来源写法）；留空时回退到部位 icon，两者都为空则显示屏障物品。
slots.<键名>.item.amountinteger否1≥ 1，小于 1 时按 1 处理物品数量。
slots.<键名>.item.componentsmap否{}—物品组件补丁，键为组件 id，值透传给该组件。
slots.<键名>.item.components.custom_namestring否——物品名称，支持 MiniMessage（组件 custom_name）。
slots.<键名>.item.components.lorelist<string>否——物品描述行，支持 MiniMessage（组件 lore）。
slots.<键名>.item.components.tooltip_display.hide_tooltipboolean否—true / false隐藏物品悬浮提示（组件 tooltip_display 的嵌套字段）。
slots.<键名>.soundsmap<string, object>否{}键为 click、left_click、right_click、shift_left_click、shift_right_click、middle_click、double_click、number_key、swap_offhand、drop、control_drop点击音效；未识别的键记录问题并被忽略。

item.components 是 CoreLib 的通用物品组件补丁，除上表列出的三个键外还接受任意 Minecraft 组件 id。饰品栏的实际交互由 type 决定，音效与自定义组件只影响外观。完整发货样例见 plugins/EmakiAccessory/gui/accessory_gui.yml。

示例：一页只用一格饰品、一个启用格和一个切页格。

yaml
id: "compact_gui"
gui_type: CHEST
title: "<dark_gray>饰品栏</dark_gray>"
rows: 3
slots:
  ring_1:
    slots: [11]
    type: "accessory_slot"
    item:
      source: "LIGHT_GRAY_STAINED_GLASS_PANE"
  page_enable:
    slots: [15]
    type: "page_enable"
    item:
      source: "lime_dye"
  main:
    slots: [16]
    type: "page_switch"
    item:
      source: "gold_ingot"
