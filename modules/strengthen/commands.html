命令与权限 ​

EmakiStrengthen 的主命令是 /emakistrengthen，别名 /estrengthen。玩家主要打开强化 GUI；管理员用命令检查主手装备、刷新展示、设置星级、清理状态和发放强化材料。

命令列表 ​

命令说明权限
/estrengthen help显示帮助。基础。
/estrengthen open打开强化 GUI。emakistrengthen.use
/estrengthen affix [recipe]打开词缀 GUI，仅玩家可执行；不填 recipe 时按当前物品匹配。use 或 admin
/estrengthen branch [branch]为主手物品选择分支，仅玩家可执行；不填参数按默认分支处理。use 或 admin
/estrengthen reload重载配置、GUI、语言和配方。reload 或 admin
/estrengthen inspect [player]检查指定玩家或自己的主手物品。use 或 admin
/estrengthen refresh [player]刷新指定玩家或自己的物品展示。admin
/estrengthen setstar <star> [recipe]设置执行者主手物品星级；没有 player 参数。admin
/estrengthen convert-legacy [confirm]把 recipes/*.yml 里已废弃的 match 块转换为 matcher + 顶层字段。不带参数只做预演；confirm（或 --apply）才实际改写，并留 .bak 备份。详见强化配方。admin
/estrengthen clearstate清除执行者主手强化层，仅玩家可执行。admin
/estrengthen clearcrack清除执行者主手锻印值，仅玩家可执行。admin
/estrengthen givecatalyst <material> [amount] [player]发放强化材料。admin
/estrengthen operation [list|<operationId>]列出已注册的强化操作，或查看单个 operationId 的详情。不填参数等同 list。admin
/estrengthen pity [list|diagnose|set|clear] ...保底计数器管理。list [group] 查看，diagnose 输出存储状态，set <scope> <group> <owner> <counter>（scope 为 player 或 item）写入计数，clear <group> 清空一个分组。不填参数等同 list。admin
`/estrengthen debug <statusplayermodule

权限节点 ​

权限默认说明
emakistrengthen.usetrue使用基础强化功能。
emakistrengthen.reloadop重载配置。
emakistrengthen.debugop调试命令。
emakistrengthen.adminop管理员功能。

先用哪个命令 ​

场景先执行目的
玩家要强化装备/estrengthen open打开强化 GUI。
修改了配方、GUI 或语言/estrengthen reload重载运行配置。
装备强化状态不对/estrengthen inspect查看主手物品的强化层和匹配配方。
展示没有刷新/estrengthen refresh <player>重建玩家物品展示。
测试某个星级效果/estrengthen setstar <star> [recipe]直接设置执行者主手物品星级。
调试异常状态/estrengthen debug ...查看模块、玩家或全局调试信息。

管理建议 ​

  • setstar、clearstate、clearcrack 都操作执行者主手物品。执行前先确认手持的是测试装备。
  • refresh 只解决展示未更新，不会替你修正错误配方。
  • 修改配方后先 reload，再用测试装备验证成功、失败、保护材料、星级写入和属性写入。
