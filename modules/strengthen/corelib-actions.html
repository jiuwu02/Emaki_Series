CoreLib 动作 ​

EmakiStrengthen 注册到 CoreLib 动作系统的段及其用途和参数如下

前置条件: EmakiStrengthen 已启用. 启用后它向 CoreLib 动作注册表追加操作主手强化层的段; 所有段都作用在目标玩家的主手物品上, 并通过 EmakiStrengthen 的服务重建或修改强化层

NOTE

仅记录 EmakiStrengthen 注册的段; CoreLib 自带通用段见 CoreLib 动作系统. 当前段 ID 只使用下表中的规范名, 不再提供历史别名入口. 旧的 emakistrengthen_set_star 现在写作 strengthen_set_star, 其余同理

段 ID ​

六个段的目标要求都是 REQUIRED_ENTITY: 目标不是玩家时该段直接跳过

段 ID用途参数
strengthen_rerender重建主手物品强化层展示无
strengthen_set_star设置主手物品强化星级star
strengthen_add_star增加主手物品强化星级amount
strengthen_remove_star扣除主手物品强化星级, 最低为 0amount
strengthen_reset_star将主手物品强化星级设为 0无
strengthen_clear_layer清除主手物品强化层无

参数 ​

参数类型必填默认值取值范围说明
starINTEGER是 (strengthen_set_star)—整数 (结果按配方 limits.max_star 钳制, 最低 0)目标星级
amountINTEGER是 (strengthen_add_star, strengthen_remove_star)—整数 (负值按 0; 结果最低 0)星级增减数量

strengthen_rerender, strengthen_reset_star, strengthen_clear_layer 不读取参数

示例 ​

yaml
actions:
  - 'self | strengthen_rerender'
  - 'self | strengthen_set_star star=8'
  - 'self | strengthen_add_star amount=1'
  - 'self | strengthen_remove_star amount=2'
  - 'self | strengthen_reset_star'
  - 'self | strengthen_clear_layer'

使用提示 ​

  • 前置条件: 玩家主手要有物品; 主手为空时该段跳过
  • 执行结果: 段把更新后的物品写回玩家主手; 强化服务无法重建物品时, 该段以失败结束
  • 验证方式: 成功时输出 old_star, new_star, has_layer 三项结果数据, 在 debug 输出里能看到这次改动前后的星级
  • 注意: 这些段是管理或管道直改的入口, 不会模拟一次完整强化尝试流程
