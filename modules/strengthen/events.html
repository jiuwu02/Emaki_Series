事件 API ​

Strengthen 提供两组 pre/post 事件, 全部同步派发在玩家 owner thread 上; post 事件只读且不可取消

事件触发时机Cancellable可修改字段取消/结果效果
StrengthenPreAttemptEvent预览/条件通过后, 摇点, 重建和扣费前是successRate, clamp 0–100阻止摇点, 重建和扣费
StrengthenAttemptEvent尝试完全解析后; 成功, 失败摇点及可报告的早期失败均可发否无post, 读取 AttemptResult, committed, outcome, operationId
StrengthenTransferEvent计算可转移星级后, 目标重建前是transferredStar, 随后按目标上限重新限制取消或最终 <=0 阻止目标重建
StrengthenTransferCompletedEvent转移成功且目标物品重建后否无post; 失败或取消不触发

事件中的 ItemStack 是防御性快照, 不代表库存槽的写入口. 公开操作返回的新 stack 仍由调用方写回. 在错误线程调用公开 API 会返回 WRONG_THREAD, 提交不会以跳过事件的方式继续
