GUI 配置 ​

Forge 的 GUI 配置位于 gui/ 目录，包括锻造 GUI 和配方书 GUI。GUI 不只是显示菜单，还负责保护输入槽、处理点击、返还物品和触发锻造流程。

文件说明 ​

文件作用
forge_gui.yml玩家执行锻造的主界面。
recipe_book.yml玩家查看已加载配方的配方书。

两个文件属于静态资源：缺失时由启动流程按内置副本创建，已存在的文件不会被改写。

模板通用字段 ​

模板使用 CoreLib GUI 模板格式。顶层字段：

字段类型必填默认值取值范围说明
idstring是—非空字符串模板 ID，即配方 gui_template 引用的名字。为空时该模板被跳过。
gui_typestring否CHEST任意 Bukkit InventoryType 名，大小写不敏感容器类型。无法解析时静默回退到 CHEST。
titlestring | object否GUI字符串或文本配置对象GUI 标题。写对象时按文本配置渲染（可作动态标题）；字符串支持 MiniMessage。
rowsinteger否31 ~ 6（超范围截断）行数。仅当 gui_type 支持行数时生效，否则按类型固定。内置 forge_gui 为 5 行，recipe_book 为 6 行。
slotsmap否空key 为槽位组名槽位组定义，见槽位组字段。某组的 slots 解析不出位置时该组被丢弃。
virtual_itemsmap否空key 为虚拟物品名不占槽位的动态展示物品，见虚拟物品。
textsmap否空见 texts 文案状态文案片段。

发货默认值（forge_gui.yml 的头部）：

yaml
id: "forge_gui"
gui_type: CHEST
title: "<dark_gray>锻造台 - %recipe%</dark_gray>"
rows: 5

可复制的最小自定义模板：

yaml
id: "my_forge_gui"
gui_type: CHEST
title: "<dark_gray>我的锻造台</dark_gray>"
rows: 6
slots:
  blueprint_inputs:
    slots: 10
  required_materials:
    slots: [19, 20, 21]
  optional_materials:
    slots: [28, 29, 30]
  capacity_display:
    slots: 16
  confirm:
    slots: 49

槽位组字段 ​

字段类型必填默认值取值范围说明
slotsinteger | list<integer>是—容器内的合法槽位索引该组占用的槽位。写成整数或索引列表都可以；解析不出位置时整组被丢弃。
typestring否由组名推断见下方两张槽位类型表功能类型。省略时按组名推断（blueprint_inputs、required_materials、optional_materials、capacity_display、confirm_button、recipe_list、prev_page、next_page、close 等）；推断不出则为纯装饰槽。
itemobject | string否空物品源字符串，或含 source / components 的对象槽位默认展示物品，见物品定义。
amountinteger否1>= 1（小于 1 提升为 1）未写 item 对象时的展示数量。
soundsmap否空见点击音效点击音效配置。未知的 key 会被忽略并记录一条模板问题。

锻造界面槽位类型 ​

forge_gui.yml 中由 type 驱动的功能槽位（Forge 实际读取的类型）：

type作用
blueprint_inputs图纸输入槽。Forge 按放入的图纸物品源自动匹配配方。
required_materials必需材料输入槽。
optional_materials可选材料输入槽，消耗锻造容量。
capacity_display展示当前容量、容量上限和容量状态。
confirm确认锻造按钮（组名写 confirm_button 也会被推断为 confirm）。

没有 type 的槽位组（内置模板中的 top_frame、side_frame、core_frame）只做背景填充。

WARNING

内置 forge_gui 不提供目标物品槽。目标物品只能由 API 调用方通过 ForgeInputs.targetItem 提供；GUI 路径下应给配方配置 result.success.outputs。

配方书槽位类型 ​

recipe_book.yml 中由 type 驱动的功能槽位：

type作用
recipe_list配方条目展示区域，槽位顺序即配方条目的排列顺序。
prev_page上一页。
next_page下一页。
close关闭菜单。

物品定义 ​

item 写成对象时，由 CoreLib 的配置物品解析器处理：

字段类型必填默认值取值范围说明
item.sourcestring否空物品源，如 anvil、minecraft-anvil展示物品来源。为空时该槽位不渲染物品。
item.amountinteger否1>= 1（小于 1 提升为 1）展示数量。
item.componentsmap否空key 为组件 ID，值按组件语义解释组件补丁。常用 custom_name、lore、tooltip_display。
item.$unsetlist<string>否空组件 ID 列表移除指定组件。
item.$resetlist<string>否空组件 ID 列表重置指定组件为默认值。
yaml
  blueprint_inputs:
    slots:
      - 10
      - 19
    type: "blueprint_inputs"
    item:
      source: "guster_banner_pattern"
      components:
        custom_name: "<light_purple>放入图纸</light_purple>"
        lore:
          - "<gray>配方会按图纸物品源自动匹配"
yaml
  confirm:
    slots:
      - 34
    type: "confirm"
    item:
      source: "ANVIL"
      components:
        custom_name: "<green>确认锻造</green>"
        lore:
          - "<gray>当前容量: <yellow>%current%/%max%</yellow>"
          - "<yellow>点击后开始执行锻造"
    sounds:
      click:
        sound: "ui.button.click"
        volume: 1.0
        pitch: 1.0

点击音效 ​

sounds 的 key 是点击类型，未知 key 会被忽略：

key触发
click任意点击
left_click / right_click左键 / 右键
shift_left_click / shift_right_clickShift + 左键 / 右键
middle_click中键
double_click双击
number_key数字键
swap_offhand交换副手
drop / control_drop丢弃 / Ctrl + 丢弃

值支持 sound / volume / pitch 三个键；sound 可写原版音效键或命名空间 ID。

锻造界面变量 ​

forge_gui 的 title 与各槽位 item 文案中可用：

变量说明
%recipe%当前匹配到的配方显示名；未匹配到配方时为 通用锻造。
%current%当前已占用容量。
%max%容量上限；未匹配到配方（上限为 0）时为 ?。
%capacity_state%容量状态文案，来自 texts.capacity_state。
%recipe_count%当前图纸可匹配的候选配方数量。
%blueprint_requirements%图纸需求行，每项各占一行；配方未确定时按配方分组列出（最多 3 组）。数量口径是「已放入 GUI 的量 / 需要的量」。

texts.capacity_state 支持四个状态键，缺失时回退到内置文案：

键条件内置回退
waiting上限为 0（尚未匹配配方）<gray>等待图纸</gray>
overflow当前容量超出上限<red>已超限</red>
warning当前容量达到上限的 80% 及以上<gold>接近上限</gold>
normal其它情况<green>正常</green>

配方书变量 ​

recipe_book 的槽位文案中可用：

变量说明
%page%当前页码，从 1 开始。
%pages%总页数。
%recipe_name%配方显示名（仅 virtual_items.recipe_entry）。
%recipe_id%配方 ID（仅 virtual_items.recipe_entry）。
%unlock_state%解锁状态文案，来自 texts.recipe_entry.unlocked / locked。
%crafted_state%锻造完成状态文案，来自 texts.recipe_entry.crafted / uncrafted。
%click_hint%点击提示，来自 texts.recipe_entry.click_hint。

虚拟物品 ​

virtual_items 定义不占固定槽位的动态展示物品。Forge 读取两个：

字段类型必填默认值取值范围说明
virtual_items.confirm_blocked.itemobject否内置 BARRIER 文案同物品定义容量超限时替换确认按钮的展示物品。
virtual_items.recipe_entry.itemobject否内置 book 文案同物品定义配方书每个配方条目的展示物品。
yaml
virtual_items:
  confirm_blocked:
    item:
      source: "BARRIER"
      components:
        custom_name: "<red>无法锻造</red>"
        lore:
          - "<gray>当前容量: <yellow>%current%/%max%</yellow></gray>"
          - "<red>可选材料容量已超出上限</red>"

texts 文案 ​

字段类型必填默认值取值范围说明
texts.capacity_state.waitingstring否<gray>等待图纸</gray>MiniMessage 文本尚未匹配配方时的容量状态文案。
texts.capacity_state.overflowstring否<red>已超限</red>MiniMessage 文本容量超出上限时的文案。
texts.capacity_state.warningstring否<gold>接近上限</gold>MiniMessage 文本容量达到上限 80% 时的文案。
texts.capacity_state.normalstring否<green>正常</green>MiniMessage 文本正常状态文案。
texts.recipe_entry.unlockedstring否<green>可用</green>MiniMessage 文本配方权限满足时的状态文案。
texts.recipe_entry.lockedstring否<red>未解锁</red>MiniMessage 文本配方权限不满足时的状态文案。
texts.recipe_entry.craftedstring否<green>已完成过锻造</green>MiniMessage 文本已锻造过该配方时的文案。
texts.recipe_entry.uncraftedstring否<gray>尚未完成锻造</gray>MiniMessage 文本尚未锻造过该配方时的文案。
texts.recipe_entry.click_hintstring否<yellow>点击打开锻造界面</yellow>MiniMessage 文本配方条目的点击提示。

玩家体验建议 ​

  • 在图纸槽和材料槽的默认展示物品 Lore 中写清楚该槽位接收什么。
  • 用 texts.capacity_state 明确区分等待图纸、接近上限和已超限，减少玩家困惑。
  • 容量超限时 confirm_blocked 会替换确认按钮，建议在 Lore 中直接说明如何解决。
  • 装饰槽位组用于分隔功能区域，调整布局时注意不要与功能槽位索引冲突。
