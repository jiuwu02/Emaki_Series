占位符参考 ​

EmakiForge 提供的占位符及其生效范围: PlaceholderAPI 占位符可在任何支持 PAPI 的位置使用, 内部模板变量只在锻造物品名称与 Lore 动作里生效

PlaceholderAPI 占位符 ​

扩展标识符: emakiforge

安装 PlaceholderAPI 后, EmakiForge 会自动注册以下占位符

占位符说明示例
%emakiforge_craft_count_<recipe_id>%玩家锻造指定配方多少次5
%emakiforge_has_crafted_<recipe_id>%玩家有没有锻造过指定配方true
%emakiforge_total_crafts%玩家所有配方的锻造次数总和42
%emakiforge_guarantee_<key>%指定保底 key 的当前计数 (key 就是配方 ID)3
%emakiforge_recipe_count%当前已经加载的锻造配方总数28
%emakiforge_last_crafted%玩家最后锻造的配方 ID; 没有记录时是空字符串flame_sword

解析规则:

  • 参数不区分大小写, 首尾的空格会被去掉
  • 玩家为 null, 或参数为空时, 返回空字符串
  • 不认识的参数返回空字符串
  • craft_count_ / has_crafted_ / guarantee_ 的配方后缀为空时分别返回 0 / false / 0

使用示例 ​

yaml
lore:
  - '<gray>锻造次数: <white>%emakiforge_craft_count_flame_sword%'
  - '<gray>总锻造: <white>%emakiforge_total_crafts%'
  - '<gray>保底进度: <yellow>%emakiforge_guarantee_flame_sword%'

内部模板变量 ​

Forge 在应用结果名称和 Lore 动作时会注入下面这些 %variable% 格式的内置变量

变量说明示例
%quality%品质名. 只有在品质档位解析成功时才会注入完美
%quality_name%品质显示名, 与 %quality% 取值相同完美
%quality_multiplier%品质倍率, 按 0.## 格式化1.2
%multiplier%品质倍率的简写别名1.2
%<stat_id>%材料效果里 variables 注入的变量累计值, 已经乘过材料数量和品质倍率10

可用位置 ​

  • 材料效果中 name_action 的 value 字段
  • 材料效果中 lore_action 的 content 字段
  • 配方 result.success.name_actions 的 value 字段
  • 配方 result.success.lore_actions 的 content 字段
  • 全局品质配置 quality.item_meta.tiers.<品质> 中的 name_actions 和 lore_actions

模板示例 ​

yaml
name_actions:
  - action: "append_suffix"
    value: " <gray>[%quality_name%]</gray>"

lore_actions:
  - action: "append"
    content:
      - ""
      - "<gray>品质: %quality_name%</gray>"
      - "<gray>品质倍率: <white>%quality_multiplier%</white></gray>"
      - "<gray>火焰伤害: <red>+%fire_damage%</red></gray>"

说明 ​

  • PlaceholderAPI 占位符可以用在任何支持 PAPI 的地方 (计分板, 聊天, 菜单等)
  • 内部模板变量只在 Forge 的 name/lore 动作里生效, 外部插件用不了
  • %<stat_id>% 是动态变量, 具体是什么取决于材料效果里 variables 配置注入的 key
  • 品质 item_meta 的 action 动作走 CoreLib 动作系统, 里面可以用 %player_name% 这类 CoreLib 通用占位符; 它和上文的内部模板变量是两套不同的机制
  • 锻造成品会被 CoreLib 变量系统暴露成 forge_recipe_id, forge_quality_id, forge_quality_display, forge_quality_multiplier 四个变量, 供 CoreLib 变量占位符使用; 数据来源见审计与签名
  • 界面文案变量 (%recipe%, %current%, %max%, %capacity_state%, %blueprint_requirements%, %page% 等) 只在界面模板里生效, 见 GUI 配置
