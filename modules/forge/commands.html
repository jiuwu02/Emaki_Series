命令与权限 ​

EmakiForge 的主命令是 /emakiforge，别名 /eforge、/ef。玩家用它打开锻造 GUI 或配方书；管理员用它重载配置、列出配方和查看运行状态。

命令列表 ​

主命令本身需要 emakiforge.use（默认 true）。子命令的额外权限如下表。

命令说明权限
/ef help显示帮助。无参数执行主命令时同样显示帮助。仅需主命令权限。
/ef forge打开锻造 GUI，仅玩家可执行。仅需主命令权限。
/ef book打开配方书，仅玩家可执行。emakiforge.book 或 emakiforge.admin
/ef list recipe列出已加载配方及显示名。recipes 也被接受，但 tab 只提示 recipe。emakiforge.admin
/ef reload重载配置、语言、GUI 模板和配方。emakiforge.reload 或 emakiforge.admin
/ef convert-legacy [confirm]当前 Forge 没有待执行的配置转换目标；命令只会按共享转换器流程报告无变更。材料和图纸应直接使用同级 item_sources + matcher（两者取 AND）。emakiforge.admin
/ef debug stats输出运行时指标与配方加载报告（status 等价）。emakiforge.debug 或 emakiforge.admin
/ef debug <player|module|...>转交 CoreLib 调试命令处理。emakiforge.debug 或 emakiforge.admin

可用的调试子模块：recipe、forge、gui、pdc。

权限节点 ​

权限默认说明
emakiforge.usetrue使用主命令与锻造 GUI。
emakiforge.booktrue打开配方书。
emakiforge.reloadop重载配置。
emakiforge.debugop输出调试信息。
emakiforge.adminop管理员权限。

先用哪个命令 ​

场景先执行目的
玩家要锻造装备/ef forge打开锻造 GUI。
玩家找不到配方/ef book查看配方是否加载。
管理员改了配方或 GUI/ef reload重载 recipes/、gui/、语言和运行时资源。
不确定配方是否加载/ef list recipe查看当前加载的配方列表。
配方加载有告警或异常/ef debug stats查看运行时指标与配方加载报告。
锻造结果异常/ef debug module forge开启 forge 子模块调试输出。

使用场景 ​

玩家打开锻造界面 ​

text
/ef forge

玩家在图纸槽放入图纸后，Forge 按图纸物品源匹配配方，再执行条件检查、容量检查、材料检查、品质计算和结果生成。

玩家查看配方书 ​

text
/ef book

配方书分页展示已加载配方。玩家看不到配方时，先用 /ef list recipe 确认配方是否加载。

管理员重载 ​

text
/ef reload

修改 recipes/、gui/ 或语言文件后使用。重载成功后会返回重载的配方数与 GUI 模板数。重载前建议先备份正在调试的配方文件。
