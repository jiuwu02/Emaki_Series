技能定义 ​

技能文件位于 skills/*.yml。EmakiSkills 负责定义技能的管理层信息，技能效果可通过原生脚本系统或 MythicMobs 执行。

字段说明 ​

字段说明
id技能唯一 ID。
enabled是否启用。
display_name显示名。
description描述。
icon_materialGUI 图标材质。
mythic_skill对应 MythicMobs 技能 ID（mythic/hybrid 模式使用）。
trigger_typeactive 或 passive。
passive_triggers被动触发器列表（详见触发器文档）。
variables运行时变量块，可在脚本动作、条件和文本中通过 %var.变量名% 引用（详见变量类型文档）。
script原生脚本系统配置块（详见脚本系统文档）。
upgrade升级规则。
cooldown_ticks冷却，单位 tick。
global_cooldown_ticks全局冷却，单位 tick。
resource_costs资源消耗或检查。
lore_aliases从 Lore 识别技能时使用的别名。
pdc_skill_id从 PDC 识别技能时使用的 ID。
tags技能标签列表，用于装备数量限制和分类筛选，配合 config.yml > skill_tags.equip_limits 生效。
tab_tagsGUI 页签标签列表。
required_skills装备此技能前必须已经装备的技能 ID 列表，别名 dependencies。默认空列表。
conflicting_skills不能与此技能同时装备的技能 ID 列表，别名 conflicts。默认空列表。
show_in_slots是否允许出现在玩家主动技能槽选择列表中。装备强制触发器技能常设为 false。
ui_categoryGUI 分类。
sort_orderGUI 排序。
condition技能释放条件块，使用 type、entries 和 required_count。

技能来源与标签上限 ​

以下两项在 plugins/EmakiSkills/config.yml 配置，影响技能如何被识别和能装备多少个。

装备技能来源开关 ​

yaml
skill_sources:
  read_lore_skills: true
  read_pdc_skills: true
  require_lore_pdc_match: false
键默认值说明
read_lore_skillstrue是否从装备 Lore 读取技能。
read_pdc_skillstrue是否从装备 PDC 读取技能。
require_lore_pdc_matchfalse严格模式。开启后只保留同一物品、同一槽位下 Lore 与 PDC 的交集，两边不一致的技能不生效。

标签装备数量限制 ​

技能定义里的 tags 命中这里的标签时，玩家最多只能同时装备对应数量：

yaml
skill_tags:
  equip_limits:
    ultimate: 1
    mobility: 2

即 tags 含 ultimate 的技能最多装备 1 个，含 mobility 的最多装备 2 个。未列出的标签不受限制。

variables 字段 ​

variables 定义运行时变量，支持 expression/string/boolean 等类型，可引用 %level%、%has_target%、%trigger_id% 等上下文变量：

yaml
variables:
  fire_damage:
    type: expression
    value: "10 + %level% * 5"
  is_enhanced:
    type: boolean
    value: "%level% >= 5"
  battle_cry:
    type: random_text
    lines:
      - "<red>燃烧吧！"
      - "<red>烈焰之力！"

NOTE

variables 同时服务于原生脚本系统的运行时计算与 MythicMobs 变量注入：解析后的值既可在脚本中通过 %var.变量名% 引用，也会注入 MythicMobs 技能元数据供 <skill.var.变量名> 读取。

script 字段 ​

原生脚本系统配置块，详见脚本系统文档。简要结构：

yaml
script:
  mode: native          # native / mythic / hybrid
  stop_on_failure: true
  actions:
    cast:
      - 'trigger | damage amount=%fire_damage%'
    hit:
      - 'trigger | ignite duration=3s'

资源消耗 ​

resource_costs 条目通常包含：

字段说明
typeea-resource、attribute-check、local-resource、auraskills-mana、mythiclib-mana。
target_id资源或属性 ID。
amount数量。
operationconsume 消耗，require 只检查。
failure_message失败提示。

auraskills-mana 需要安装 AuraSkills，mythiclib-mana 需要安装 MythicLib 或 MMOCore；对应插件不存在时该条目视为不可用。

升级配置 ​

字段说明
upgrade.enabled是否启用升级功能。默认 false。
upgrade.max_level最大等级。默认 1，小于 1 时被抬升为 1。
upgrade.gui_template升级 GUI 模板名（默认 upgrade_gui）。留空时同样回退到 upgrade_gui。
upgrade.failure_penalty升级失败惩罚：none（无惩罚）或 downgrade（降级）。默认 none。
upgrade.success_rates按目标等级配置成功率 Map（如 5: 90.0）。未配置的等级取 100.0。
upgrade.economy.enabled是否启用经济消耗。默认 false。
upgrade.economy.currencies货币列表，每项含 provider、currency_id、base_cost、cost_formula、display_name。
upgrade.levels.<n>.materials该等级所需物品材料列表。每项支持 item_sources、amount、optional、protection。判定由 item_sources（允许的物品源）与同级 matcher（组件、PDC、Lore 等非物品源条件）取 AND 合成，两者都省略时该材料永不命中，见 物品匹配器。
upgrade.levels.<n>.economy该等级覆盖经济配置，含 enabled（默认 true）与 currencies。
upgrade.levels.<n>.success_rate该等级覆盖成功率，优先于 upgrade.success_rates。
upgrade.levels.<n>.actions.success升级成功后执行的动作列表。
upgrade.levels.<n>.actions.failure升级失败后执行的动作列表。

levels 的键必须大于 1

upgrade.levels 下的 <n> 是目标等级，只解析大于 1 的整数键。1 以及非整数键会被静默跳过，不报错。此外 <n> 必须写成映射节点，写成标量值同样被跳过。

cost_formula 支持变量：%base_cost%、%level%、%target_level%、%max_level%。

最小示例 ​

yaml
id: fireball
enabled: true
display_name: '<red>火球术'
description:
  - '<gray>向前方释放一枚火球。'
icon_material: FIRE_CHARGE
mythic_skill: EmakiFireball
trigger_type: active
cooldown_ticks: 100
global_cooldown_ticks: 20
resource_costs:
  - type: ea-resource
    target_id: mana
    amount: 20
    operation: consume
    failure_message: '<red>法力不足。'
