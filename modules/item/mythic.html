MythicMobs 集成 ​

让 MythicMobs 的 Drops 直接掉落 EmakiItem 物品的配置, 参数和写法如下, 按示例原样填写即可

前置条件: 服务器已安装 MythicMobs. 满足后即可在 MythicMobs 的 Drops 中直接掉落 EmakiItem 物品, 不需要把物品复制成 MythicMobs 自己的物品定义

启用条件 ​

paper-plugin.yml 中 MythicMobs 是 dependencies.server 可选依赖; 没装 MythicMobs 时 EmakiItem 会跳过这个桥接, 不影响其他功能

主配置:

yaml
mythicmobs:
  enabled: true
  drops:
    enabled: true
    names:
      - "emakiitem"
      - "ei_item"
字段类型必填默认值取值范围说明
mythicmobs.enabledboolean否truetrue / falseMythicMobs 集成的总开关. 关掉后不注册任何 Drop
mythicmobs.drops.enabledboolean否truetrue / false是否注册 MythicMobs 自定义 Drop
mythicmobs.drops.nameslist否emakiitem, ei_item—能识别的 Drop 名称; 留空时回退到默认值. 名称会先做小写与空格转下划线的规范化, 再拿来比对

生效方式: 改完配置后执行 /ei reload; 注册发生在插件启用阶段, 所以改 mythicmobs.enabled 或 mythicmobs.drops.enabled 需要重启服务器. 验证方式: 生效后按下面格式写的 Drop 在怪物死亡时掉落对应 EmakiItem 物品

自定义 Drop ​

最小示例:

yaml
Drops:
  - emakiitem{id=example_item}

带数量:

yaml
Drops:
  - emakiitem{id=example_item;amount=1}
  - ei_item{id=starter_sword;amount=2}

参数:

参数默认说明
id无 (必填)EmakiItem 物品 ID. 缺失或解析不到定义时会跳过本次掉落并输出警告
amount1基础数量. 可以是数字, 也可以是表达式
amount_formula%amount% * %drop_amount%最终数量公式

amount_formula 变量:

变量说明
%amount%amount 参数解析后的基础数量
%drop_amount%MythicMobs 传入的 Drop 数量倍率
%metadata_amount%MythicMobs DropMetadata 的 amount
%generations%MythicMobs DropMetadata generations
%tick%MythicMobs DropMetadata tick
%id%目标 EmakiItem 物品 ID
%drop%实际匹配到的 Drop 名称

amount 本身不是纯数字时, 也会先当作表达式来算. 这时能用的变量包括 %drop_amount%, %metadata_amount%, %generations% 和 %tick%

最终数量向下取整; 结果小于等于 0 时跳过发放, 超过物品最大堆叠数时按最大堆叠数截断

Drop 示例 ​

固定掉落一件 ​

yaml
Drops:
  - emakiitem{id=example_item;amount=1}

按 Drop 数量倍率缩放 ​

yaml
Drops:
  - emakiitem{id=example_item;amount=1;amount_formula="%amount% * %drop_amount%"}

如果 MythicMobs 把该 Drop 的数量倍率传为 3, 最终掉落 3 件

Boss 按生成次数增加数量 ​

yaml
Drops:
  - ei_item{id=starter_sword;amount=1;amount_formula="%amount% + %generations%"}

物品内容说明 ​

Drop 生成的物品与 /ei give 得到的物品一致: 走同一个物品工厂, 所以随机变量, PDC 身份, 属性数据, 技能绑定和套装归属都会正常写入. 带随机元素的物品每次掉落都会重新求值

与 EmakiLevel 的 Drop 区别 ​

模块Drop 类型效果
EmakiItem实物 Drop掉落一件 EmakiItem 物品
EmakiLevel非实物 Drop不生成物品, 直接给玩家等级经验

两者可以写在同一个 Drops 列表中
