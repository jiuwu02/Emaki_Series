EmakiItem ​

EmakiItem 是轻量自定义物品模块，提供稳定物品 ID、基础属性、套装、触发动作、自动更新与 PlaceholderAPI 支持。它适合作为装备成长线的起点：先生成一件有稳定 ID 的装备，再交给 Forge、Strengthen、Gem、Attribute 和 Skills 继续扩展。

基本信息 ​

项目值
模块版本2.8.1
主命令/emakiitem
别名/ei
硬依赖EmakiCoreLib
软依赖EmakiAttribute、EmakiSkills、MythicMobs、PlaceholderAPI
权限节点emakiitem.use、emakiitem.give、emakiitem.browse、emakiitem.inspect、emakiitem.update、emakiitem.reload、emakiitem.debug、emakiitem.admin

功能页面 ​

页面内容
命令与权限列出与发放物品、检查手持物与组件、刷新物品与套装、重载与调试。
物品定义与套装items/*.yml 与 sets/*.yml 的字段、物品 ID 到 ItemStack 的生成规则。
物品浏览 GUI/ei browse 的两级浏览界面、pack.yml 物品包元数据与槽位类型。
触发器交互、攻击、投射物、方块、丢弃等事件中执行动作。
物品更新策略物品定义变更后把玩家手上的旧物品更新到新版本。
物品修复系统耐久归零后的禁用状态与材料/货币修复流程。
跨模块集成被 Attribute、Forge、Strengthen、Gem、Skills、Cooking 引用时的物品来源写法。
MythicMobs 集成在 MythicMobs 的 Drops 中掉落 EmakiItem 物品。
占位符PlaceholderAPI 输出。
CoreLib 动作主手物品更新、重绘、修复、耐久与原版 Data Component 动作。
API通过 EmakiItemApi 创建、识别与查询物品。
事件 API物品流程的 Bukkit 事件与拦截点。

核心能力 ​

能力说明
稳定物品 ID用配置 ID 标识物品，不依赖显示名。
物品组件配置材质、名称、Lore、模型、附魔、flags、耐久等。
属性写入可向 Attribute 提供属性 payload。
技能绑定可让物品提供技能或技能解锁信息。
套装系统根据装备件数触发属性、技能或 Lore。
触发器在交互、攻击、投射物、方块、丢弃等事件中执行动作。
自动更新玩家登录、切换手持、点击背包、拾取等场景刷新物品。
修复系统耐久归零后进入禁用状态，可用材料或货币修复。
浏览界面两级 GUI 按物品包浏览全部物品，可直接取出。
ID alias 与迁移支持物品 ID 改名映射，并可批量迁移配置与玩家背包。

默认配置目录 ​

text
plugins/EmakiItem/
├── config.yml
├── id_aliases.yml
├── items/
├── sets/
├── gui/
└── lang/

items/ 定义物品，sets/ 定义套装，gui/ 存放修复界面与两级浏览界面模板（repair_gui.yml、pack_browser_gui.yml、item_browser_gui.yml），id_aliases.yml 保存物品 ID 改名映射。

items/ 的每个子目录都是一个物品包，可放一份 pack.yml 定义它在浏览界面里的图标，详见物品浏览 GUI。

主配置 ​

config.yml 只包含全局设置，物品行为写在各自的定义文件里。「必填」按源码是否有回退判定：以下键都有回退，因此全部为「否」。「取值范围」写源码真实约束，源码未校验的写「—」。

顶层设置 ​

字段类型必填默认值取值范围说明
versionstring否"2.8.1"—配置结构标记，由项目资源同步流程维护，不是功能开关。缺失时回退 2.6.7。
languagestring否zh_CN—语言文件名，对应 lang/<language>.yml。缺失时回退 zh_CN。
release_default_databoolean否truetrue / false是否在启动时释放 items/、sets/ 等内置默认数据；关闭后只加载已有数据，不主动生成缺失的默认示例。config.yml 与语言文件不受此项控制。
yaml
# 发货默认值
version: "2.8.1"
language: "zh_CN"
release_default_data: true

使用示例：切换到英文并停止释放默认示例数据。

yaml
language: "en_US"
release_default_data: false

data_directories ​

字段类型必填默认值取值范围说明
data_directoriesobject否——数据目录扫描设置，作用于 items/ 与 sets/。
data_directories.max_depthint否2>= 1（源码按 max(1, 值) 处理）子目录递归深度上限，含数据目录本身：1 只读取目录根部的 .yml，2 允许一层子目录，3 允许两层。超过上限的目录会被跳过并记录警告。
yaml
# 发货默认值
data_directories:
  max_depth: 2

使用示例：允许读取两层子目录（例如 items/<物品包>/<子目录>/*.yml）。

yaml
data_directories:
  max_depth: 3

set_bonus ​

字段类型必填默认值取值范围说明
set_bonusobject否——套装加成设置。套装定义位于 sets/*.yml，物品通过自身配置声明所属套装和部位。
set_bonus.enabledboolean否truetrue / false是否启用套装加成系统。关闭后不计算也不应用任何套装加成。
set_bonus.refresh_triggersobject否——套装刷新触发器。玩家装备变化、背包变化或命令刷新时重新计算当前已穿戴/持有的套装件数和加成；未写出的项按 true 处理。
set_bonus.refresh_triggers.joinboolean否truetrue / false玩家进服时刷新套装状态。
set_bonus.refresh_triggers.held_changeboolean否truetrue / false玩家切换手持物品时刷新。
set_bonus.refresh_triggers.inventory_clickboolean否truetrue / false玩家点击背包时刷新。
set_bonus.refresh_triggers.inventory_dragboolean否truetrue / false玩家拖拽物品时刷新。
set_bonus.refresh_triggers.pickupboolean否truetrue / false玩家拾取物品时刷新。
set_bonus.refresh_triggers.interactboolean否truetrue / false玩家交互时刷新。
set_bonus.refresh_triggers.commandboolean否truetrue / false执行 EmakiItem 相关命令时允许触发套装刷新。
yaml
# 发货默认值
set_bonus:
  enabled: true
  refresh_triggers:
    join: true
    held_change: true
    inventory_click: true
    inventory_drag: true
    pickup: true
    interact: true
    command: true

使用示例：关掉高频的背包点击与拖拽刷新，只保留低频触发。

yaml
set_bonus:
  refresh_triggers:
    inventory_click: false
    inventory_drag: false

item_state ​

字段类型必填默认值取值范围说明
item_stateobject否——物品自定义状态设置，写入 emaki:item_state PDC，由 item_state_* 动作段与 API 读写。整段为增量配置：不写任何内容时行为与旧版本一致。
item_state.clampboolean否truetrue / false是否按 fields 声明的 min/max 钳制写入值。关闭后仅保留溢出保护，不做配置化钳制。
item_state.fill_defaultsboolean否truetrue / falseadd 操作在字段缺失时是否用 fields 的 default 作为起始值。关闭后字段缺失仍直接拒绝（reason=missing_state）。
item_state.fieldsmap否{}—字段声明，键名即状态键名（写入时统一小写）。未声明字段不受钳制、默认值或阈值影响。
item_state.migrationsmap否{}—按 schema 版本的迁移步骤；空映射不迁移。
item_state.preservationobject否——状态保全策略。
item_state.derivationobject否——状态变更驱动的派生刷新。

item_state.fields ​

字段类型必填默认值取值范围说明
item_state.fields.<key>object否——单个字段声明，<key> 即状态键名。
item_state.fields.<key>.typestring否doubleINTEGER / LONG / DOUBLE / BOOLEAN / STRING（大小写不敏感）字段类型。空值或无法识别的类型会使该字段整体被跳过；min/max/thresholds 仅数值类型（INTEGER、LONG、DOUBLE）生效。
item_state.fields.<key>.default标量否无需能被 type 强转字段缺失且 fill_defaults 开启时用作 add 的起始值。无法强转时为无默认值。
item_state.fields.<key>.minnumber否无数值钳制下界，仅 clamp 开启且字段为数值类型时生效。
item_state.fields.<key>.maxnumber否无数值钳制上界。
item_state.fields.<key>.thresholdsmap否{}—阈值集合，键为阈值 ID。每字段最多保留按 value 升序最小的 64 个，与书写顺序无关；阈值集合变化会重新武装该字段的 once latch。
item_state.fields.<key>.thresholds.<id>.valuenumber是无数值触发阈值。缺失该键的阈值条目会被丢弃。
item_state.fields.<key>.thresholds.<id>.onceboolean否falsetrue / false是否只奖励一次，直到被重新武装。
item_state.fields.<key>.thresholds.<id>.reward_on_fallboolean否falsetrue / false数值向下跨过阈值时是否也触发。
item_state.fields.<key>.thresholds.<id>.actionslist否空—跨过阈值时执行的动作列表。
item_state.fields.<key>.thresholds.<id>.message_keystring否""—阈值提示使用的语言键。
item_state.fields.<key>.thresholds.<id>.soundstring否""—跨过阈值时播放的音效。
item_state.fields.<key>.thresholds.<id>.sound_volumedouble否1.0—音效音量。
item_state.fields.<key>.thresholds.<id>.sound_pitchdouble否1.0—音效音高。
item_state.fields.<key>.thresholds.<id>.refresh_derivedboolean否truetrue / false该阈值触发后是否执行派生刷新。

item_state.migrations ​

字段类型必填默认值取值范围说明
item_state.migrations.<key>object否——单个迁移步骤，<key> 仅作标识。
item_state.migrations.<key>.fromint是无—起始 schema 版本。缺失，或 to <= from 时该步被跳过。
item_state.migrations.<key>.toint是无> from目标 schema 版本。
item_state.migrations.<key>.renamemap否空—字段重命名，写法 旧字段名: 新字段名；源与目标相同的条目会被忽略。
item_state.migrations.<key>.retypemap否空目标类型同 type字段改类型，写法 字段名: 类型。
item_state.migrations.<key>.droplist否空—丢弃的字段名列表。

item_state.preservation ​

字段类型必填默认值取值范围说明
item_state.preservation.verify_rebuildboolean否truetrue / false物品 rebuild 后校验状态是否仍在，缺失时用重建前快照回填；只在状态确实丢失时才写入，正常路径为无操作。
item_state.preservation.repair_on_pickupboolean否falsetrue / false拾取时修复损坏的状态元数据。
item_state.preservation.repair_on_dropboolean否falsetrue / false丢弃时修复损坏的状态元数据。
item_state.preservation.repair_on_tradeboolean否falsetrue / false交易时修复损坏的状态元数据。
item_state.preservation.repair_on_container_transferboolean否falsetrue / false容器转移时修复损坏的状态元数据。
item_state.preservation.repair_on_joinboolean否falsetrue / false玩家进服时修复损坏的状态元数据。

item_state.derivation ​

字段类型必填默认值取值范围说明
item_state.derivation.enabledboolean否falsetrue / false派生刷新总开关。默认关闭，避免为既有服务器引入额外刷新开销。
item_state.derivation.refresh_loreboolean否truetrue / false派生刷新时刷新套装 Lore。
item_state.derivation.refresh_attributesboolean否truetrue / false派生刷新时同步属性。
item_state.derivation.scan_holderboolean否truetrue / false允许在缺少持有者信息时扫描在线玩家定位物品。
item_state.derivation.max_depthint否21 ~ 8（源码按 clamp(值, 1, 8) 处理）派生刷新与阈值奖励的最大递归深度，用于阻断自触发循环。
yaml
# 发货默认值
item_state:
  clamp: true
  fill_defaults: true
  preservation:
    verify_rebuild: true
    repair_on_pickup: false
    repair_on_drop: false
    repair_on_trade: false
    repair_on_container_transfer: false
    repair_on_join: false
  derivation:
    enabled: false
    refresh_lore: true
    refresh_attributes: true
    scan_holder: true
    max_depth: 2

使用示例：声明一个带阈值的击杀计数，并按 schema 版本迁移旧字段。

yaml
item_state:
  fields:
    kills:
      type: INTEGER
      default: 0
      min: 0
      max: 9999
      thresholds:
        novice:
          value: 10
          once: true
          message_key: "state.kills.novice"
          sound: "minecraft:entity.player.levelup"
          sound_volume: 1.0
          sound_pitch: 1.2
        veteran:
          value: 100
          actions:
            - 'send_message text="<gold>连杀达标</gold>"'
  migrations:
    "1":
      from: 0
      to: 1
      rename:
        kill_count: kills
      retype:
        kills: LONG
      drop:
        - legacy_tag

proficiency_guard ​

字段类型必填默认值取值范围说明
proficiency_guardobject否——熟练度派发防刷设置，作用于 damage_dealt / kill_entity / kill_player 的槽位派发。除 dedupe_per_event 外全部默认关闭或无限，不改变既有获取速率。
proficiency_guard.dedupe_per_eventboolean否truetrue / false同一物品定义在一次事件中只派发一次，修复「同一定义同时存在于多个槽位时按槽各触发一次」。
proficiency_guard.max_dispatches_per_eventint否0>= 0（源码按 max(0, 值) 处理）；0 表示不限制单次事件最多派发次数。
proficiency_guard.same_target_cooldown_secondsnumber否0>= 0（内部换算为毫秒）；0 表示无冷却对同一目标的冷却秒数。
proficiency_guard.daily_soft_capint否0>= 0（源码按 max(0, 值) 处理）；0 表示无上限每日软上限。计数保存在内存中，按服务器本地日期跨天重置，不跨重启保留。
proficiency_guard.decay_factordouble否1.0(0, 1]；越界或非有限值回退 1.0超过软上限后的递减系数。1.0 表示不递减（超限直接拒绝）。
proficiency_guard.decay_minimum_ratiodouble否0.0[0, 1]（源码按 clamp 处理）递减后的最低通过概率下限。
proficiency_guard.guarded_triggerslist否damage_dealt、kill_entity、kill_player—受本段约束的触发器名单；为空时回退默认三项。
yaml
# 发货默认值
proficiency_guard:
  dedupe_per_event: true
  max_dispatches_per_event: 0
  same_target_cooldown_seconds: 0
  daily_soft_cap: 0
  decay_factor: 1.0
  decay_minimum_ratio: 0.0
  guarded_triggers:
    - "damage_dealt"
    - "kill_entity"
    - "kill_player"

使用示例：限制单次事件派发次数，并对同一目标加 1 秒冷却。

yaml
proficiency_guard:
  max_dispatches_per_event: 3
  same_target_cooldown_seconds: 1

mythicmobs ​

字段类型必填默认值取值范围说明
mythicmobsobject否——MythicMobs 集成设置。未安装 MythicMobs 时自动跳过，不影响其他功能。
mythicmobs.enabledboolean否truetrue / falseMythicMobs 集成总开关。关闭后不注册任何 Drop。
mythicmobs.dropsobject否——自定义 Drop 设置。
mythicmobs.drops.enabledboolean否truetrue / false是否注册 MythicMobs 自定义 Drop。
mythicmobs.drops.nameslist否emakiitem、ei_item—可识别的 Drop 名称；为空时回退默认值。
yaml
# 发货默认值
mythicmobs:
  enabled: true
  drops:
    enabled: true
    names:
      - "emakiitem"
      - "ei_item"

使用示例：只用自定义的 Drop 名称。

yaml
mythicmobs:
  drops:
    names:
      - "emakiitem"

相互作用 ​

set_bonus.refresh_triggers 控制套装状态刷新；物品自动更新由物品定义的 update.triggers 单独控制，二者互不覆盖。

item_state.* 作用于 emaki:item_state PDC 分区，由 item_state_* 动作段与 API 读写，全部为增量配置：不写任何内容时行为与旧版本一致。proficiency_guard.* 作用于 damage_dealt、kill_entity、kill_player 的槽位派发，除 dedupe_per_event 外全部默认关闭或无限。

典型物品生命周期 ​

  1. 在 items/ 中定义物品 ID、材质、名称、Lore 和组件。
  2. 可选写入 Attribute 属性、Skills 技能或 set 信息。
  3. 管理员通过命令发放物品。
  4. 玩家使用装备。
  5. Item 在触发时机自动更新物品状态。
  6. Forge / Strengthen / Gem 可继续在该物品上写入自己的 layer。
  7. CoreLib 统一重建最终展示。

与其他模块的关系 ​

EmakiForgeForge 可以改造 EmakiItem 生成的装备。
EmakiStrengthenStrengthen 可以强化 EmakiItem 装备。
EmakiGemGem 可以给 EmakiItem 装备开孔和镶嵌。
MythicMobsMythicMobs 怪物可以通过 Drops 掉落 EmakiItem 物品。
