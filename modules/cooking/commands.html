命令与权限 ​

EmakiCooking 的主命令是 /ecooking，别名为 /ec。管理员主要用它重载工位配置、检查手持物/目标方块来源、重建工位索引和查看运行调试信息。

命令列表 ​

命令权限说明
/ec helpemakicooking.use显示帮助。
/ec reloademakicooking.reload 或 emakicooking.admin重载主配置、语言、工位、配方、GUI 与物品调整。
/ec inspect handemakicooking.inspect、emakicooking.use 或 emakicooking.admin检查手持物来源和烹饪匹配情况。
/ec inspect blockemakicooking.inspect、emakicooking.use 或 emakicooking.admin检查准星 6 格内目标方块的工位类型、方块状态、TileState、PDC/YAML 后端和索引状态。
/ec station reindexemakicooking.admin重建工位坐标索引，扫描 legacy YAML 与当前已加载区块中的 PDC 工位。
/ec convert-legacy [confirm]emakicooking.admin将配置中的旧扁平 matcher 键迁移为同级 item_sources + matcher 或嵌套角色节点；发酵桶 inputs[] 保留旧键以兼容持久化槽位身份。不带参数只预演，带 confirm（或 --apply）才写盘并保留备份。
/ec debug [status|on|off|player <玩家>|module <模块>]emakicooking.debug 或 emakicooking.admin输出运行时调试信息，见下方子命令说明。

营养命令 ​

/ec nutrition 用于查询和管理玩家营养值。营养玩法说明见 营养系统。

命令权限说明
/ec nutrition get [玩家] [类型]emakicooking.nutrition.use、emakicooking.nutrition.admin 或 emakicooking.admin查询营养值。不带类型列出全部类型的 值 / 上限；带类型返回单类型当前值。玩家可省略（默认查自己，控制台必须指定）。
/ec nutrition set <玩家> <类型> <数值>emakicooking.nutrition.admin 或 emakicooking.admin设置指定玩家某营养类型的值。
/ec nutrition add <玩家> <类型> <数值>emakicooking.nutrition.admin 或 emakicooking.admin增加指定玩家某营养类型的值。
/ec nutrition remove <玩家> <类型> <数值>emakicooking.nutrition.admin 或 emakicooking.admin减少指定玩家某营养类型的值。
  • set、add、remove 需要四段参数齐全，目标玩家必须在线，数值写入后按类型 min~max 截断。
  • 营养系统未启用时，营养命令会提示已禁用。

先用哪个命令 ​

场景先执行目的
改了工位、配方、GUI 或语言/ec reload重载 Cooking 运行配置。
材料、燃料或容器不匹配/ec inspect hand查看手持物被识别成什么物品来源。

迁移旧 YAML、换方块或重启后工位缺失/ec station reindex重建 data/stations/index/<world>.idx 坐标索引。
工位监听或展示异常/ec debug查看运行时状态和调试输出。

常见操作 ​

检查手持物来源 ​

text
/ec inspect hand

用于确认手持物是否能被识别为配方输入、容器、燃料、工具或工位方块。排查自定义物品来源时优先使用该命令。

检查目标工位方块 ​

text
/ec inspect block

用于查看准星 6 格内目标方块的工位类型、物品来源、block_state、tile_state、storage_backend、pdc_state、indexed、index_backend 和 legacy_yaml。大量工位服务器可用它确认锚点是否走 BLOCK_PDC，从而减少独立 YAML 文件 IO。

重建工位坐标索引 ​

text
/ec station reindex

用于扫描旧 YAML 状态和当前已加载区块中的 PDC 工位，重建 data/stations/index/<world>.idx。迁移旧数据、替换方块实体或发现 ChunkLoad 后工位未恢复时优先执行。

重载烹饪配置 ​

text
/ec reload

重载后建议检查控制台输出。如果新增了工位方块、GUI 或配方目录，建议在测试服先验证状态保存与交互流程。

调试运行状态 ​

text
/ec debug
/ec debug status
/ec debug on
/ec debug off
/ec debug player <玩家>
/ec debug module <模块>
子命令说明
不带参数 / status输出当前调试开关、被跟踪玩家和已开启模块。
on / off全局开启或关闭调试输出。
player <玩家>切换只跟踪该在线玩家；省略玩家名时列出可用模块。
module <模块>切换单个模块的调试输出。EmakiCooking 可用模块：recipe、stir、display、station、pdc（另含 CoreLib 共享模块）。

无法识别的子命令会回退为输出状态。适合排查工位监听、展示实体、配方匹配、持久化状态等问题。正式服长期排查时，建议配合控制台日志使用，避免玩家端信息过多。

排查建议 ​

  • 工位无法使用：检查方块来源、工位权限和交互方式是否匹配。
  • 工位状态或后端不确定：对准目标方块执行 /ec inspect block，确认 tile_state、storage_backend、pdc_state、indexed 和 legacy_yaml。
  • 重启或区块加载后工位未恢复：先执行 /ec station reindex 重建索引，再观察控制台是否出现 lost_block_entity_replaced 或 mismatch 报告。
  • 材料无法放入：检查 input_rules.only_recipe_items、配方目录和物品来源。
  • 榨汁机无法盛取：检查流体容量是否达到容器 serving_ml，并确认玩家拥有 emakicooking.station.juicer.collect。
  • 发酵桶无法开始：检查输入是否匹配配方、玩家是否拥有 start 权限。
  • 烤炉不推进：检查火力是否处于配方要求区间，燃料是否生效。
