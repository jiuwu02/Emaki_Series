从 PlayerKits 2 迁移 ​

本页给把 PlayerKits 2 迁到 EmakiKits 的服主. 对照只写有据可依的部分 (依据 PlayerKits 2 资源页与 wiki 目录), 不确定处标注「待确认」

概念映射 ​

PlayerKits 2EmakiKits说明
kit 定义kits/*.ymlEmakiKits 一文件一礼包, id 取文件内 id 字段
Cooldown周期礼包 / max_claims_totalPlayerKits 2 是冷却时间 (单位以其文档为准); EmakiKits 用周期键或累计上限近似, 秒级冷却不支持 (待确认)
One Timemax_claims_total: 1一次性礼包
Permission Required礼包 permission 字段节点改为 emakikits. 前缀并同步权限插件
Requirements: Pricepurchase 段price / max_purchases / 经济桥选择
Actions on claimaction 奖励EmakiKits 走 CoreLib 动作管道; on error 动作无对应 (待确认)
First join kitjoin 类型礼包join.on_first_join: true
Kit preview/ekits preview不显示权重, 不预测抽取结果
Kit Edit GUI/ekits edit1.0.6 起提供全 GUI 编辑器
Kit Display Items 四态(无对应)待确认
Auto Armor / Auto Offhand(无对应)待确认
Inventory.yml 自建菜单(无对应)EmakiKits 不做自建总览菜单
MySQL(无)EmakiKits 仅 data/store.yml; SQLite / MySQL 明确不做 (等全系统一数据库方案)

命令映射 ​

PlayerKits 2EmakiKits
/kit <kit> 或 /kit claim <kit>/ekits claim <礼包ID>
/kit (GUI)(无对应总菜单, 待确认)
/kit edit <kit>/ekits edit <礼包ID>
/kit create <kit>/ekits edit 浏览器内新建
/kit give <kit> <player>/ekits grant <玩家> <礼包ID> (语义近似: PlayerKits 2 直接发放且忽略条件, EmakiKits grant 是增加一次可领取次数)
/kit delete/ekits edit 内删除
/kit reset ...(无对应, 待确认)

数据迁移 ​

  • EmakiKits 的礼包定义是 plugins/EmakiKits/kits/*.yml, 运行数据是 plugins/EmakiKits/data/store.yml, 与 PlayerKits 2 的配置与数据互不相通
  • 没有自动导入: 礼包定义按上表人工改写; PlayerKits 2 的领取 / 冷却记录不导入, 迁移后从空记录开始
  • PlayerKits 2 wiki 的 Migrating 章节只覆盖它自己的 v1 升级, 与跨插件迁移无关

迁移步骤建议 ​

  1. 测试服安装 EmakiCoreLib + EmakiKits, 按概念映射表逐个改写礼包定义
  2. /ekits check 确认加载状态, /ekits preview 核对奖励内容
  3. 切换权限节点与命令绑定, 验证领取 / 购买 / 预览
  4. 确认无误后再下线 PlayerKits 2
