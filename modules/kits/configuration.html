配置与礼包定义 ​

EmakiKits 的配置分两层: plugins/EmakiKits/config.yml 是全局开关, plugins/EmakiKits/kits/*.yml 是礼包定义, 一个礼包一个文件

config.yml ​

键类型默认值说明
versionstring1.0.1资源版本, 由模块版本同步流程维护
languagestringzh_CN使用 lang/<language>.yml
release_default_databooleantrue首次启动是否释放内置示例礼包与 lang
timezonestringAsia/Shanghai每日/每周/每月礼包未单独指定 cycle.timezone 时使用
join.missed_window_secondslong7200新玩家入服后允许输入邀请码的游玩时长窗口 (秒), 超时不补领
join.invite_code_typestringuuid邀请码类型: uuid 或 name
storage.backendstringyaml存档后端, 当前仅 yaml
storage.save_delay_ticksint20脏数据延迟落盘间隔 (tick)
storage.atomic_writesbooleantrue是否 tmp + move 原子替换
economy.providerstringautoauto / vault / excellenteconomy
economy.currency_idstring""ExcellentEconomy 货币 id, Vault 留空
invite.enabledbooleantrue邀新总开关
invite.require_new_playerbooleantrue被邀请人是否必须是首次入服
invite.allow_mutualbooleanfalse是否允许互邀链
invite.max_binds_per_inviteeint1同一被邀请人最多绑定次数
invite.new_player_markerslist[first_join]新玩家判定标记
cdk.case_sensitivebooleanfalse兑换码是否区分大小写
cdk.max_codes_per_kitint10000单礼包兑换码数量上限
nested.max_depthint4嵌套子礼包递归深度上限 (1-16)
nested.count_pass_to_nestedbooleanfalse子礼包开启计数是否向父礼包传递

kits/*.yml 顶层字段 ​

字段必填说明
id是礼包唯一 id, 仅小写字母, 数字, 下划线与连字符; 与文件名无关
type是join / invite / daily / weekly / monthly / cdk / choice / generic
enabled否 (默认 true)是否启用
display_name否 (默认 id)玩家可见名称
permission否 (默认 emakikits.claim)领取所需权限, 必须以 emakikits. 开头
max_claims_total否 (默认 0)累计领取上限, 0 为不限
join / invite / cycle / cdk / choice / purchase / open / limit / rewards否按类型与功能取用, 见下

加载期会校验 id 合法性, 重复 id, 未知类型, 权限前缀, 时区, CDK 兑换码, 自选数量, 购买上限, 开启档位, 奖励字段, 限时模式, 以及嵌套礼包的自引用 / 循环 / 缺失 / 深度; 有问题的礼包文件会被跳过并输出告警

四类奖励 ​

rewards.fixed 是固定发放, rewards.random 在 rewards.weighted: true 时按 weight 加权抽取一条, 否则全部发放. choice.options.<选项>.rewards 与 open.milestones.<次数>.rewards 用同样的条目格式

type字段说明
itemsource (必填), amountsource 是 CoreLib 物品来源简写 (minecraft-bread, emakiitem-flame_blade, itemsadder-xxx), 经 EmakiCoreLibApi.createConfiguredItem 生成物品并放入背包, 溢出物品掉落在脚下
moneyamount经 CoreLib 经济桥给玩家加钱
nested_kitkit_id (必填)展开另一个 kits/*.yml 礼包的奖励, 受 nested.max_depth 限制
actionaction (必填)一条完整的 CoreLib 动作管道行, 由 executeActionLineAsync 执行, caster 为领取玩家; 省略 source 时默认 self

公共字段: id (条目标识), permission (可选, 玩家无权限时跳过该条), weight (仅加权随机用)

NOTE

action 奖励异步执行: 领取的幂等键在动作提交前已写入, 动作失败会记审计与 WARNING 日志, 但不回滚整次领取. 可用变量: %var.kit%, %var.player%, %var.uuid%, %var.amount%

yaml
rewards:
  weighted: true
  fixed:
    - type: "item"
      id: "welcome_bread"
      source: "minecraft-bread"
      amount: 8
    - type: "action"
      id: "welcome_msg"
      action: 'send_message text="<green>欢迎加入服务器!</green>"'
  random:
    - type: "money"
      id: "roll_money"
      amount: 200
      weight: 5
    - type: "nested_kit"
      id: "roll_nested"
      kit_id: "nested_child"
      weight: 1

自选礼包与内联 GUI ​

choice 礼包的每个选项是一个"小礼包": rewards 里可写多条奖励, 也可用 kit_id 引用另一个礼包文件. min_select / max_select 控制可选数量, max_select: 1 即只能选一个

每个礼包在 choice.gui 段内联自己的 GUI 布局 (复用 CoreLib GuiTemplateParser): gui_type, title, rows, slots. 槽位 type 为 choice_option 的键必须与 choice.options 的键一致, confirm 槽位提交选择. 也可改用 choice.gui_template 指向 gui/ 下的外部模板 id

yaml
choice:
  min_select: 1
  max_select: 1
  gui:
    id: "choice_starter_gui"
    gui_type: CHEST
    title: "<dark_gray>新手自选 - <gold>%kit%</gold></dark_gray>"
    rows: 3
    slots:
      sword:
        type: "choice_option"
        slots: [10]
        item:
          source: "minecraft-iron_sword"
          components:
            custom_name: "<aqua>战士小礼包</aqua>"
      confirm:
        type: "confirm"
        slots: [22]
        item:
          source: "minecraft-emerald_block"
  options:
    sword:
      display: "战士小礼包"
      rewards:
        - type: "item"
          source: "minecraft-iron_sword"
          amount: 1
        - type: "item"
          source: "minecraft-bread"
          amount: 4
        - type: "action"
          action: 'heal amount=2'

限时窗口 limit ​

仅 enabled: true 时生效, mode 三选一:

mode字段说明
always—不限时
rangestart, endISO-8601 时间戳闭区间
croncron (6 字段), duration_seconds, timezoneCoreLib cron 表达式, 每次触发后开窗 duration_seconds 秒

购买与开启次数 ​

  • purchase: enabled, price, economy_provider, currency_id, max_purchases (0 不限), count_pass_to_nested. 价格 > 0 且经济桥不可用时购买一律拒绝
  • open: enabled, max_opens (0 不限), milestones.<次数>.rewards 累计开启到指定次数时追加发放
