EmakiKits ​

EmakiKits 是配置驱动的礼包模块: 入服, 邀新, 每日, 每周, 每月, CDK, 自选与通用礼包都由 YAML 定义, 不同类型的差异只体现在配置上

  • 礼包定义放在 plugins/EmakiKits/kits/ 下, 一个礼包一个 YAML 文件, 礼包 id 取自文件内的 id 字段, 与文件名无关
  • 奖励物品引用 CoreLib 物品来源简写 (minecraft-bread, emakiitem-flame_blade 等), 不再在礼包里手搓材质和 Lore
  • 奖励共四类: item (物品), money (货币), nested_kit (引用另一个礼包), action (CoreLib 动作管道行)
  • 自选礼包的每个选项是一个"小礼包" (多条奖励), 通过 max_select: 1 实现只能选一个; 每个礼包在 choice.gui 段内联自己的 GUI 布局
  • 支持固定奖励, 加权随机奖励, 购买扣费, 累计开启次数档位, 限时窗口 (always / range / cron), 嵌套子礼包与循环引用检测
  • 领取, 兑换, 购买都走幂等键与审计记录, 重启后可恢复

礼包类型 ​

type触发方式
join新玩家首次进服, 需在游玩时长窗口内输入老玩家邀请码 (UUID 或玩家名)
invite邀新关系绑定后按 reward_target 发放
daily / weekly / monthly按 cycle.timezone 的周期边界生成周期键, 每周期一次
cdk/emakikits redeem 兑换, 支持全局一次性与每玩家一次性
choice打开内联 GUI 选择一个小礼包, max_select 控制可选数量
generic手动领取, 可叠加购买, 开启次数档位与限时窗口

配置目录 ​

text
plugins/EmakiKits/
├── config.yml                  # 主配置 (版本, 语言, 存储, 经济, 邀新, CDK, 嵌套, 入服窗口)
├── kits/
│   ├── join_welcome.yml        # 一文件一礼包, id 取自文件内 id 字段
│   ├── invite_reward.yml
│   ├── daily_login.yml
│   ├── weekly_supply.yml
│   ├── monthly_crate.yml
│   ├── cdk_global.yml
│   ├── cdk_per_player.yml
│   ├── choice_starter.yml      # 含内联 choice.gui 布局
│   ├── generic_crate.yml
│   └── nested_child.yml        # 被其他礼包引用
├── gui/                        # 可选外部 GUI 模板 (choice.gui_template 回退用)
├── data/                       # 运行期存档 (审计, 幂等键, 计数)
└── lang/
    ├── zh_CN.yml
    └── en_US.yml

release_default_data: true 时首次启动释放内置的 10 个示例礼包; 已有文件不会被覆盖

依赖与集成 ​

模块关系
EmakiCoreLib硬依赖: 物品来源, createConfiguredItem, 动作管道, GUI 服务, 模板加载, 经济桥, cron 与消息服务
EmakiItem可选: 通过 emakiitem-<物品ID> 简写发放其自定义物品
Vault / ExcellentEconomy可选: money 奖励与 purchase 扣款经 CoreLib 经济桥; 未安装时价格 > 0 的购买一律拒绝

上手步骤 ​

  1. 安装 EmakiCoreLib 与 EmakiKits, 首次启动后确认 plugins/EmakiKits/kits/ 下已释放示例礼包
  2. 复制一份 kits/*.yml 改写 id, type 与 rewards, 用 /emakikits reload 热重载
  3. 用 /emakikits list 确认礼包已加载, 用 /emakikits claim <礼包ID> 验证
  4. 自选礼包用 /emakikits choose <礼包ID> 打开内联 GUI; choose 后直接跟选项 id 则跳过 GUI
