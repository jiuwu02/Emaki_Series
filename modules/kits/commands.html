命令与权限 ​

EmakiKits 的主命令是 /emakikits, 别名 /emakikit 与 /ekits. 所有子命令先检查 emakikits.use, 再按子命令检查对应权限

玩家命令 ​

命令作用权限
/emakikits help显示可用子命令emakikits.use
/emakikits list列出已加载礼包 (类型, id, 显示名, 是否启用)emakikits.use
/emakikits claim <礼包ID>领取礼包emakikits.claim
/emakikits choose <礼包ID> [选项...]不带选项打开自选 GUI; 带选项 id 直接提交选择emakikits.open
/emakikits buy <礼包ID>购买一次可领取次数 (经 CoreLib 经济桥扣费)emakikits.buy
/emakikits redeem <礼包ID> <兑换码>兑换 CDK 礼包emakikits.redeem
/emakikits invite <玩家名>绑定邀新关系 (被邀请人需在线)emakikits.invite
/emakikits open <礼包ID>领取礼包, 与 claim 等价emakikits.open

管理命令 ​

命令作用权限
/emakikits inspect <玩家名>查看该玩家的审计记录条数与明细emakikits.inspect
/emakikits grant <玩家名> <礼包ID>给玩家增加一次可领取次数emakikits.grant
/emakikits cdk list列出 CDK 礼包及其兑换码数量emakikits.cdk
/emakikits cdk disable <兑换码>停用兑换码emakikits.cdk
/emakikits reload重新加载 config.yml, kits/*.yml, lang 与 GUI 模板, 并重注册 cron 窗口emakikits.reload

权限表 ​

权限默认说明
emakikits.usetrue使用玩家命令的根权限
emakikits.claimtrue领取礼包
emakikits.opentrue打开自选 GUI / 领取已购买礼包
emakikits.buytrue购买礼包
emakikits.redeemtrue兑换 CDK
emakikits.invitetrue绑定邀新关系
emakikits.adminop管理权限父节点, 含下列子权限
emakikits.reload / grant / inspect / cdkop分别对应重载, 发放, 审计, CDK 管理

Tab 补全 ​

一级子命令 (help, list, claim, choose, buy, redeem, invite, open, inspect, grant, cdk, reload) 与需要礼包 id 的子命令第二参数 (来自 kits/*.yml 的 id 集合) 提供补全

说明 ​

  • CDK 礼包不能通过 claim 领取, 必须用 redeem; 邀新礼包通过入服邀请码流程绑定, 不走 claim
  • choose 带选项 id 时按 min_select / max_select 校验数量, 权限与未配置选项, 然后发放该选项小礼包内的全部奖励
  • 领取, 兑换与购买失败时返回对应语言键 (如 error.kit.already_claimed, error.cdk.exhausted), 不会静默吞掉
