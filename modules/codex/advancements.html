成就页定义 ​

一个 advancements/*.yml 文件定义一个原版成就标签页。本页说明页面与节点字段、注册 key 规则、PacketEvents 坐标通道与完成动作。

NOTE

本页只讲原版 Advancement。codex/*.yml 的分类条目是另一套模型，其 category_id 与这里的 page_id 互不替代，见分类条目 GUI。

自动授予的触发器写法见事件触发器。

advancements/*.yml ​

基础结构：

yaml
page_id: "example"
title: "<gradient:#F59E0B:#EC4899>图鉴示例</gradient>"
background: "minecraft:textures/gui/advancements/backgrounds/adventure.png"
root: "root"

advancements:
  root:
    icon: "minecraft-enchanted_book"
    title: "<gold>图鉴之路</gold>"
    description: "<gray>开启你的探索之旅。</gray>"
    frame: "task"
    x: 0.0
    y: 1.0
    toast: false
    announce: false
    hidden: false
    actions:
      complete: []

页面字段：

字段类型说明
page_idstring成就页 ID，也作为原版 key 的路径前缀。必填；为空时整页会被跳过。示例节点会注册为 emakicodex:example/root。
titleMiniMessage string标签页标题。省略时回退为 page_id。
backgroundstring原版成就页背景材质路径，例如 minecraft:textures/gui/advancements/backgrounds/adventure.png。省略时使用 minecraft:textures/gui/advancements/backgrounds/stone.png。
rootstring根节点本地 ID，必须对应 advancements 下的一个节点。
advancementsmap节点定义。key 是节点本地 ID。

节点字段：

字段类型默认说明
iconItemSource stringminecraft-book节点图标，使用 CoreLib ItemSource 简写，例如 minecraft-diamond。
titleMiniMessage string节点 ID节点标题。
descriptionMiniMessage string空节点描述。
framestringtask原版框样式：task、goal、challenge；未知值回退 task。
parentstring空父节点本地 ID；根节点不写。
xnumber0.0成就界面 X 坐标，仅 PacketEvents 坐标通道生效。
ynumber0.0成就界面 Y 坐标，仅 PacketEvents 坐标通道生效。
toastbooleantrue完成时是否显示原版 toast。
announcebooleanfalse完成时是否广播。
hiddenbooleanfalse是否隐藏到完成前。
actions.completelist空节点首次完成时执行的 CoreLib Action 列表。
triggers.entrieslist空自动授予触发器列表，见事件触发器。

节点 key 规则 ​

EmakiCodex 会把节点注册为：

text
emakicodex:<page_id>/<node_id>

例如：

text
emakicodex:example/root
emakicodex:example/first_step
emakicodex:example/challenge

命令、API 与 Action 可使用短写 example/first_step，也可使用完整 key emakicodex:example/first_step。

PacketEvents 坐标规则 ​

x / y 只有在满足以下条件时才影响客户端成就界面：

  1. 服务器安装并启用 PacketEvents。
  2. config.yml > advancement.packet_coordinates: true。
  3. 节点至少一个坐标不是 0.0。

注意：

  • x=0.0 且 y=0.0 会被视为“未设置”，该节点回退为客户端自动排布。
  • 建议同一页所有节点都写坐标，避免显式坐标节点和自动排布节点重叠。
  • 未安装 PacketEvents 时，Advancement 仍正常注册，只是不注入坐标。

只要 advancement.enabled: true，玩家加入服务器后会被延迟重推一次成就数据，让坐标与最新注册结果在登录时即刻生效。

完成动作 actions.complete ​

actions.complete 是 CoreLib Action 字符串列表，会在节点首次完成时执行。

yaml
advancements:
  first_step:
    actions:
      complete:
        - "send_message text=<green>你迈出了图鉴之路的第一步！</green>"
        - "give_item item=minecraft-diamond amount=1"

行为说明：

  • 节点通过命令、API、Action 或触发器完成时，都会走同一套原版 Advancement 完成链路。
  • 对已完成节点重复授予不会再次完成，也不会重复执行 actions.complete。
  • 动作上下文有玩家时才适合执行需要玩家目标的动作。
