技能触发器 ​

生物定义中的 actions 节点将触发器事件与 CoreLib 动作管道绑定。动作由 EmakiCoreLib 的动作管道执行（CoreLib 是硬依赖），不需要安装 EmakiSkills。旧键 skills 仍作为兼容回退，读取时会提示 WARN，建议迁移。

触发器列表 ​

触发器触发时机上下文对象
on_spawn生物刷出（MobFactory 内，在 Boss 血条与模型挂载之后立即执行）—
on_death生物死亡killer（击杀者，仅在存在存活击杀者时提供）
on_target生物锁定新目标target（仅在目标非空时提供）
on_damage_give该生物作为攻击者造成伤害target（仅在受击者是生物实体时提供）
on_damage_take该生物受到伤害attacker（仅在攻击者是生物实体时提供）
on_kill生物击杀某实体victim（被击杀实体）
on_shoot生物射出弹射物—
on_explode生物爆炸（如苦力怕）—
on_teleport生物传送—
on_transform生物变形（如僵尸猪灵变身）—
on_health_threshold_<百分比>生物血量首次降到该百分比及以下—

「上下文对象」列出的对象由 EmakiMobs 通过 CoreLib 的动作上下文键传入；未提供时对应的源段（如 killer）返回空结果，该动作行不会被选中执行。没有伤害量对象（on_damage_give / on_damage_take 都不提供 damage），需要伤害数值请改用 CoreLib 的其他手段。

血量阈值触发器 ​

on_health_threshold_<百分比> 的百分比档位是固定的五档，只有以下五个键名会被触发：

on_health_threshold_90
on_health_threshold_75
on_health_threshold_50
on_health_threshold_25
on_health_threshold_10

写其他数字（如 on_health_threshold_80）不会报错，但永远不会触发。

每个档位对同一只生物只触发一次。生物受到伤害时按 90 → 10 的顺序检查，一次伤害跨过多个档位时，被跨过的档位会在同一次伤害中依次触发。阈值以 当前生命值 / 最大生命值属性值 计算，最大生命值属性缺失或不为正时不做阈值检查。

NOTE

血量阈值随伤害事件一并检测，因此 on_damage_take 与命中的阈值触发器会同时执行。

动作字符串格式 ​

每个触发器对应一组 CoreLib 动作管道字符串，格式为：

[选择器 |] 动作名 [参数=值 ...]

常用选择器 ​

选择器来源说明
selfCoreLib触发该事件的生物自身（管道施法者）。
targetEmakiMobs当前事件的目标实体（on_target、on_damage_give）。
killerEmakiMobs击杀该生物的实体（on_death）。
victimEmakiMobs被该生物击杀的实体（on_kill）。
attackerEmakiMobs攻击该生物的实体（on_damage_take）。
nearby radius=<n> include_players=trueCoreLib半径范围内的实体。玩家默认被排除：include_players 默认 false，只写 type=player 会选不出任何目标，必须显式加 include_players=true。

四个 EmakiMobs 注册的选择器（target / killer / victim / attacker）依赖上文列出的上下文对象，只有在对应触发器的事件中存在该对象时才能解析出目标。

动作示例 ​

yaml
actions:
  on_spawn:
    # 向附近 20 格内所有玩家发送消息
    - "nearby radius=20 include_players=true | send_message text='<red>精英僵尸降临！'"
    # 在自身位置播放粒子效果
    - "self | spawn_particle particle=FLAME count=30 offset_x=0 offset_y=1 offset_z=0"

  on_death:
    # 向击杀者给予经验
    - "killer | give_exp amount=80"
    # 向附近玩家广播消息
    - "nearby radius=50 include_players=true | send_message text='<green>精英僵尸已被击败！'"

  on_damage_give:
    # 对被攻击目标施加减速效果
    - "target | give_potion_effect type=SLOWNESS level=1 duration=3s"

  on_damage_take:
    # 受伤时在自身位置产生火焰粒子
    - "self | spawn_particle particle=FLAME count=10 offset_x=0 offset_y=1 offset_z=0"

  on_target:
    # 锁定目标时播放音效
    - "self | play_sound sound=minecraft:entity.skeleton.ambient volume=1.0 pitch=0.7"

EmakiMobs 注册的源段与动作段 ​

除 CoreLib 内置内容外，EmakiMobs 向动作系统注册了 8 个段（启动日志会输出注册数量与期望值 8）：4 个源段 attacker / killer / victim / target，4 个动作段 summon_mob / mob_play_animation / mob_stop_animation / mob_set_model。动作行编译失败时会在控制台输出 技能编译错误: mob=<id> trigger=<触发器> line=<行号> reason=<原因>，该行被跳过，同触发器其他行继续执行。

summon_mob — 召唤生物定义 ​

在目标位置召唤一只 EmakiMobs 生物定义。

参数类型必填默认值取值范围说明
mob_idstring是无已加载的生物定义 id（区分大小写）要召唤的生物定义；缺失或空白按配置错误（INVALID_CONFIG）返回，未注册的 id 同样按配置错误返回。
countint否1≥ 1（小于 1 按 1 处理）召唤数量；逐个在目标位置生成。
yaml
actions:
  on_damage_take:
    # 在自身位置召唤两只火焰守卫
    - "self | summon_mob mob_id=fire_guardian count=2"

  on_health_threshold_50:
    # 半血时在击杀者位置召唤一只随从
    - "killer | summon_mob mob_id=boss_minion"

该动作需要目标能解析出位置（执行域为位置区域）。目标没有位置时返回 skipped；全部召唤都失败时返回 INTERNAL_ERROR。

模型动作段 ​

mob_play_animation、mob_stop_animation、mob_set_model 的参数与行为见实体模型与动画的「动作段」一节。

NOTE

动作字符串的完整语法和可用动作列表由 EmakiCoreLib 提供。请参阅 CoreLib 文档了解所有可用动作及其参数格式。
