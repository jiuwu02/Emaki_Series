组件参考 ​

components 节点下的字段由 ComponentMapper 直接映射到 Minecraft 实体属性或数据组件。键名必须与本页列表逐字一致：查不到处理器的键会被静默跳过（不报错、不打日志）。

发货示例：首次启动释放的 mobs/example_zombie.yml 与插件内置的 mobs/elite_zombie.yml、mobs/bone_lord.yml 都使用了下表中的字段，可直接对照阅读。

下表的「必填」一律为「否」——组件整体可缺省，未写入的键不会被应用；「默认值」一律为「—」，表示不写入时保留原版或实体自身状态。「取值范围」写「—」表示源码未做校验（数值会被原样写入，越界行为由原版属性/实体 API 决定）。

生成与刷新语义 ​

  • 仅生成时应用：absorption、freeze_ticks、fire_ticks、potion_effect、全部装备类字段（helmet、chestplate、leggings、boots、main_hand、off_hand、equipment）。这些是消耗性状态，/emakimobs reload 触发的刷新不会重置它们，也不会补回损坏或已失去的装备。
  • max_health 特殊处理：生成时应用上限后立即补满血量；刷新时保留当前血量并按新上限截断（上限升高不会回血，上限降低会截断到新上限）。
  • 其余组件（属性类与外观行为类）每次刷新都会按配置重新写入。

属性类字段 ​

字段类型必填默认值取值范围说明
max_healthdouble否——最大生命值（原版属性 MAX_HEALTH）。
movement_speeddouble否——移动速度（原版僵尸约 0.23，玩家 0.1）。
attack_damagedouble否——近战攻击伤害。
attack_speeddouble否——攻击速度。
attack_knockbackdouble否——攻击时施加的击退力度。
follow_rangedouble否——（格）追踪目标的最大距离。
knockback_resistancedouble否—0.0–1.0（原版属性范围）抗击退值，1.0 为完全免疫击退。
armordouble否——护甲值。
armor_toughnessdouble否——护甲韧性。
luckdouble否——幸运值。
flying_speeddouble否——飞行速度（适用于飞行生物）。
scaledouble否——实体渲染缩放倍率，1.0 为原版大小。
step_heightdouble否——可直接跨上的方块高度。
jump_strengthdouble否——跳跃强度（马等可骑乘生物）。
safe_fall_distancedouble否——不产生摔落伤害的下落高度。
fall_damage_multiplierdouble否——摔落伤害倍率。
burning_timedouble否——着火后的燃烧时长倍率。
explosion_knockback_resistancedouble否——爆炸击退抗性。
spawn_reinforcementsdouble否—0.0–1.0（原版属性范围）僵尸召唤援军的概率。
oxygen_bonusdouble否——水下呼吸加成。
water_movement_efficiencydouble否——水中移动效率。
movement_efficiencydouble否——地面移动效率。

NOTE

以上均为原版实体属性（Attribute）。属性在目标实体上不存在时该项被忽略（例如给僵尸写 flying_speed）。

外观与行为类字段 ​

字段类型必填默认值取值范围说明
custom_namestring否—任意字符串实体展示名，支持 MiniMessage 格式（与 display_name 字段不同，这里会真正改写实体名牌）。
custom_name_visibleboolean否—true / false是否始终显示名牌；false 则仅靠近时显示。
persistentboolean否—true / false是否持久化（不因区块无玩家而自然消失）。
silentboolean否—true / false是否屏蔽该生物的音效。
invulnerableboolean否—true / false是否无敌（免疫所有伤害）。
no_aiboolean否—true / falsetrue 时禁用 AI（生物停止移动和攻击）。
glowingboolean否—true / false是否发光（显示轮廓）。
gravityboolean否—true / false是否受重力影响。
collidableboolean否—true / false是否参与实体碰撞（推挤）。
fire_immuneboolean否—true / false是否免疫火焰伤害；true 时写入实体 PDC，并取消着火与火焰/岩浆类伤害事件。
visual_fireboolean否—true / false是否强制显示着火视觉效果（不产生实际伤害）。
absorptiondouble否——（点）初始伤害吸收量（黄心）。（仅生成时应用）
freeze_ticksint否——（tick）初始冰冻 tick 数（细雪效果）。（仅生成时应用）
fire_ticksint否——（tick）初始着火 tick 数。（仅生成时应用）

掉落类字段 ​

字段类型必填默认值取值范围说明
loot_tablestring否—<命名空间>:<路径> 或裸路径（会自动补 minecraft:）双职责键：其值交给 Bukkit.getLootTable 查询原版/数据包掉落表（插件不注册数据包，故自定义命名空间值通常查不到，此时静默 no-op）；而它的存在性是 loot_tables/<mob_id>.yml 的启用开关。
can_pick_up_lootboolean否—true / false生物是否能捡起地上的物品。
remove_when_farboolean否—true / false玩家远离后是否自动移除（覆盖 persistent）。

loot_table 的行为与直觉相反

  • 只有写了 loot_table 键，死亡时才会读取并应用 loot_tables/<mob_id>.yml；一旦该 YAML 表存在，死亡时会执行 event.getDrops().clear()，清空全部原版掉落（击杀经验仍按 experience 保留）。
  • 若想保留原版掉落，就不要写 loot_table 键——代价是同名的 YAML 掉落表也不会生效。
  • 写 loot_table: "minecraft:entities/zombie" 这类原版键会额外设置原版掉落表，但同时存在同名 YAML 表时原版掉落仍会被清空。插件自带的示例写的是 emakimobs:entities/<mob_id>，该值查不到表，仅起开关作用。

装备类字段 ​

字段类型必填默认值取值范围说明
main_handItemConfig 或材质名否—见下方 ItemConfig主手物品（仅生成时应用）。
off_handItemConfig 或材质名否—同上副手物品（仅生成时应用）。
helmetItemConfig 或材质名否—同上头盔（等价于 equipment.head，仅生成时应用）。
chestplateItemConfig 或材质名否—同上胸甲（等价于 equipment.chest，仅生成时应用）。
leggingsItemConfig 或材质名否—同上腿甲（等价于 equipment.legs，仅生成时应用）。
bootsItemConfig 或材质名否—同上靴子（等价于 equipment.feet，仅生成时应用）。
equipmentmap否—键为槽位名，值为 ItemConfig 或材质名用一个节点统一配置多个槽位（仅生成时应用）。

equipment 下的槽位名接受以下写法（大小写不敏感）：

槽位可用键名
主手main_hand、hand
副手off_hand
头部helmet、head
胸部chestplate、chest
腿部leggings、legs
脚部boots、feet

ItemConfig 的字段：

字段类型必填默认值取值范围说明
itemstring否—原版材质名（大小写不敏感，可带 minecraft: 前缀）仅接受「是物品」的原版材质；匹配失败时该槽位保持原样。
drop_chancedouble否—（保持原版默认掉落率）0.0–1.0死亡时掉落概率；0.0 表示不掉落。未做本地钳制，越界取值由原版装备 API 决定。
yaml
components:
  main_hand:
    item: "minecraft:iron_sword"
    drop_chance: 0.05
  helmet:
    item: "minecraft:iron_helmet"
    drop_chance: 0.0
  equipment:
    legs:
      item: "minecraft:iron_leggings"
      drop_chance: 0.0
    # 只指定物品时可以省略 ItemConfig，直接写材质名
    feet: "minecraft:iron_boots"

特殊生物字段 ​

字段类型必填默认值取值范围说明
is_babyboolean否—true / false是否为幼年形态。仅对 Ageable 与 Zombie 生效，其他生物忽略。
creeper_poweredboolean否—true / false是否为充能苦力怕。仅对苦力怕生效。
creeper_explosion_radiusint否——爆炸半径。仅对苦力怕生效。
angryboolean否—true / false是否处于愤怒状态。仅对狼生效。
wolf_variantstring否—minecraft:wolf_variant 注册表键（如 pale、woods、ashen）狼的变种。仅对狼生效，键无法识别时忽略。
horse_colorstring否—WHITE、CREAMY、CHESTNUT、BROWN、BLACK、GRAY、DARK_BROWN马匹颜色。仅对马生效，枚举无法识别时忽略。
horse_stylestring否—NONE、WHITE、WHITE_FIELD、WHITE_DOTS、BLACK_DOTS马匹花纹。仅对马生效。
cat_typestring否—minecraft:cat_variant 注册表键（如 tabby、siamese、calico、all_black）猫品种。仅对猫生效。
parrot_variantstring否—RED、BLUE、GREEN、CYAN、GRAY鹦鹉变种。仅对鹦鹉生效。
frog_variantstring否—minecraft:frog_variant 注册表键（如 temperate、warm、cold）青蛙变种。仅对青蛙生效。
axolotl_variantstring否—LUCY、WILD、GOLD、CYAN、BLUE美西螈变种。仅对美西螈生效。
llama_colorstring否—CREAMY、WHITE、BROWN、GRAY羊驼花色。仅对羊驼生效。
llama_strengthint否—1–5羊驼力量值（决定箱子容量）。仅对羊驼生效。
slime_sizeint否——史莱姆大小（1 = 小，2 = 中，4 = 大）。仅对史莱姆/岩浆怪生效。
phantom_sizeint否——幻翼体型。仅对幻翼生效。
fox_typestring否—RED、SNOW狐狸种类。仅对狐狸生效。
rabbit_typestring否—BROWN、WHITE、BLACK、BLACK_AND_WHITE、GOLD、SALT_AND_PEPPER、THE_KILLER_BUNNY兔子种类。仅对兔子生效。
mushroom_typestring否—RED、BROWN蘑菇牛种类。仅对蘑菇牛生效。
panda_main_genestring否—NORMAL、LAZY、WORRIED、PLAYFUL、BROWN、WEAK、AGGRESSIVE熊猫显性基因。仅对熊猫生效。
panda_hidden_genestring否—同上熊猫隐性基因。仅对熊猫生效。
goat_screamingboolean否—true / false是否为尖叫山羊。仅对山羊生效。
can_break_doorsboolean否—true / false是否能破门。仅对僵尸类生效。
villager_typestring否—minecraft:villager_type 注册表键（如 desert、plains、taiga）村民生物群系类型。仅对村民/僵尸村民生效。
villager_levelint否—1–5村民职业等级（新手到大师）。仅对村民/僵尸村民生效。
villager_professionstring否—minecraft:villager_profession 注册表键（如 armorer、farmer、librarian）村民职业。仅对村民/僵尸村民生效。

生物类型不匹配时该项被跳过；枚举或注册表键无法识别时同样被跳过（不报错、不打日志）。

药水效果字段 ​

字段类型必填默认值取值范围说明
potion_effectstring 或 string list否—冒号分隔的效果串，见下表生物生成时自带的药水效果（仅生成时应用）。单条效果可直接写字符串，多条写字符串列表。

每条效果是一个冒号分隔的字符串：

text
<效果类型>:<持续 tick>[:<效果等级>]
段必填说明
效果类型是原版效果 ID，大小写不敏感（speed、regeneration、fire_resistance 等），按 minecraft: 命名空间查表。
持续 tick是持续时间，单位 tick；必须能解析为整数。
效果等级否省略时为 0（即 I 级），1 为 II 级。
yaml
components:
  potion_effect:
    - "speed:99999:1"
    - "regeneration:600"
  # 单条效果也可以直接写成字符串
  # potion_effect: "fire_resistance:1200"

不支持映射写法

potion_effect 只解析上面的冒号字符串。写成 - type: SPEED / duration: / amplifier: 这类映射不会报错，但整条效果被丢弃。ambient、particles、icon 不是可配置项。效果类型无法识别、缺少持续时间、数字无法解析时，该条同样被静默跳过。
