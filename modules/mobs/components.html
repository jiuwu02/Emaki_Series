组件参考 ​

components 节点下的字段由 ComponentMapper 直接映射到 Minecraft 实体属性或数据组件。

属性类字段 ​

字段类型说明
max_healthdouble最大生命值。
movement_speeddouble移动速度（原版默认约 0.25）。
attack_damagedouble近战攻击伤害。
attack_speeddouble攻击速度。
attack_knockbackdouble攻击击退力度。
follow_rangedouble追踪目标的最大距离（格）。
knockback_resistancedouble抗击退值，范围 0.0–1.0。
armordouble护甲值。
armor_toughnessdouble护甲韧性。
luckdouble幸运值。
flying_speeddouble飞行速度（适用于飞行生物）。
spawn_reinforcementsdouble僵尸召唤援军概率，范围 0.0–1.0。
step_heightdouble可直接跨上的方块高度。
jump_strengthdouble跳跃强度（马等可骑乘生物）。
safe_fall_distancedouble不产生摔落伤害的下落高度。
fall_damage_multiplierdouble摔落伤害倍率。
burning_timedouble着火后的燃烧时长倍率。
explosion_knockback_resistancedouble爆炸击退抗性。
oxygen_bonusdouble水下呼吸加成。
water_movement_efficiencydouble水中移动效率。
movement_efficiencydouble地面移动效率。

NOTE

以上均为原版实体属性（Attribute）。属性在目标实体上不存在时该项被忽略。max_health 生效后会把当前生命值补满到新上限。

外观与行为类字段 ​

字段类型说明
custom_namestring实体展示名，支持 MiniMessage 格式。
custom_name_visibleboolean是否始终显示名牌；false 则仅靠近时显示。
persistentboolean是否持久化（不因区块无玩家而自然消失）。
silentboolean是否屏蔽所有生物音效。
invulnerableboolean是否无敌（免疫所有伤害）。
no_aiboolean是否禁用 AI（生物停止移动和攻击）。
glowingboolean是否发光（显示轮廓）。
gravityboolean是否受重力影响。
fire_ticksint初始着火 tick 数。
freeze_ticksint初始冰冻 tick 数（细雪效果）。
absorptiondouble初始伤害吸收量（黄心）。
visual_fireboolean是否强制显示着火视觉效果（不产生实际伤害）。

掉落类字段 ​

字段类型说明
loot_tablestring关联的掉落表键，格式 <namespace>:entities/<mob_id>，对应 loot_tables/<mob_id>.yml。
can_pick_up_lootboolean生物是否能捡起地上的物品。
remove_when_farboolean玩家远离后是否自动移除（覆写 persistent）。

装备类字段 ​

字段类型说明
main_handItemConfig主手物品，顶层快捷写法。
off_handItemConfig副手物品，顶层快捷写法。
helmetItemConfig头盔，顶层快捷写法（等价于 equipment.head）。
chestplateItemConfig胸甲，顶层快捷写法（等价于 equipment.chest）。
leggingsItemConfig腿甲，顶层快捷写法（等价于 equipment.legs）。
bootsItemConfig靴子，顶层快捷写法（等价于 equipment.feet）。
equipment.<槽位>ItemConfig用一个 equipment 节点统一配置多个槽位。

equipment 下的槽位名接受以下写法（大小写不敏感）：

槽位可用键名
主手main_hand、hand
副手off_hand
头部helmet、head
胸部chestplate、chest
腿部leggings、legs
脚部boots、feet

每个 ItemConfig 支持：

字段说明
item物品 ID，仅支持原版材质名称，格式 minecraft:<id>（如 minecraft:diamond_sword）。
drop_chance死亡时掉落概率，范围 0.0–1.0；0.0 表示不掉落。
yaml
components:
  main_hand:
    item: "minecraft:iron_sword"
    drop_chance: 0.05
  helmet:
    item: "minecraft:iron_helmet"
    drop_chance: 0.0
  equipment:
    legs:
      item: "minecraft:iron_leggings"
      drop_chance: 0.0
    # 只指定物品时可以省略 ItemConfig，直接写材质名
    feet: "minecraft:iron_boots"

未知组件键被静默忽略

components 下的键要与本页表格逐字一致。ComponentMapper 按键名查处理器，查不到就跳过该项，既不报错也不打日志。拼错的键（例如把 no_ai 写成 noai）不会有任何提示。

字段适用生物说明

药水效果字段 ​

字段类型说明
potion_effectstring 或 string list生物生成时自带的药水效果。单条效果可直接写字符串，多条写字符串列表。

每条效果是一个冒号分隔的字符串：

text
<效果类型>:<持续 tick>[:<效果等级>]
段必填说明
效果类型是原版效果 ID，大小写不敏感（speed、regeneration、fire_resistance 等）。
持续 tick是持续时间，单位 tick。
效果等级否省略时为 0（即 I 级），1 为 II 级。
yaml
components:
  potion_effect:
    - "speed:99999:1"
    - "regeneration:600"
  # 单条效果也可以直接写成字符串
  # potion_effect: "fire_resistance:1200"

不支持映射写法

potion_effect 只解析上面的冒号字符串。写成 - type: SPEED / duration: / amplifier: 这类映射不会报错，但整条效果被丢弃。ambient、particles、icon 不是可配置项。效果类型无法识别、缺少持续时间、数字无法解析时，该条同样被静默跳过。
