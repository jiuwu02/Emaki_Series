实体模型与动画 ​

EmakiMobs 可将自定义生物挂载到 ModelEngine 或 BetterModel 渲染的 3D 模型上，并驱动标准动作、关键帧（K帧）事件与距离分级（LOD）。两个模型后端均为可选依赖：未安装任何后端时，模型功能静默禁用，生物照常以原版形态运行。

安装前提 ​

  1. 安装 ModelEngine（付费）或 BetterModel（免费开源）插件本体。
  2. 在对应插件的 blueprints/ 目录放入 Blockbench 导出的 .bbmodel 蓝图，并生成/接入含模型贴图的资源包。
  3. 在 EmakiMobs 的 config.yml 的 model: 节选择后端（见下文）。
  4. 在生物定义 YAML 中写入 model: 节（见下文）。

蓝图名在两个后端中的解析规则由各自插件决定；EmakiMobs 只按字符串名查询，不做二次加工。

主配置 model: 节 ​

字段类型必填默认值取值范围说明
apistring否autoauto / model_engine / better_model（另接受别名 modelengine / bettermodel，大小写不敏感）auto 自动选择（优先 ModelEngine，其次 BetterModel）。取值非法时预检报 WARN 并回退 auto；指定或选中的后端未安装时模型功能禁用并打印提示。
view_distancedouble否48.0—（格）模型视距。仅 ModelEngine 在 NEAR/MID 档用它设置模型可见范围；BetterModel 不使用该值。
lod.neardouble否16.0需 ≤ lod.midLOD 下界（格）。距离 ≤ 该值为 NEAR。
lod.middouble否32.0需 ≥ lod.near、≤ lod.farLOD 中界（格）。near–mid 之间为 MID；超过 mid 即为 FAR（mid–far 之间同样是 FAR），因此它是隐藏的实际分界点。
lod.fardouble否48.0需 ≥ lod.mid只用于限定「附近是否有玩家」的搜索半径（far + 8）与远距早退判定，不是隐藏分界点；小于 lod.mid 会使 MID 档不可达。
movement_check_interval_ticksint否5≥ 1（tick）移动状态（idle/walk/run）与 LOD 的检测周期；档位或状态变化时才下发给模型后端。
death_detach_delay_ticksint否40≥ 0（tick）死亡动画开始后延迟多少 tick 卸载模型实体。
walk_speed_thresholddouble否0.12—（格/tick）水平速度达到该值判定为行走。
run_speed_thresholddouble否0.28—（格/tick）水平速度达到该值判定为奔跑（优先于行走阈值判断）。
transitions.<动作>_fade_ticksint否idle/walk/run 为 5，death 为 0，hurt 为 2，attack/skill/interact 为 3≥ 0（tick）过渡混合时长，交给模型引擎原生补间。<动作> 只认 idle、walk、run、death、hurt、attack、skill、interact 八个固定键，其他键不被读取；负值按 0 处理。

当前两个后端对 NEAR 与 MID 的处理完全相同（都正常渲染，没有中间降频）；FAR 时 ModelEngine 把模型视距设为 0、BetterModel 暂停该模型的 tracker。

强制使用 BetterModel 并把中距档收紧到 24 格：

yaml
model:
  api: "better_model"
  lod:
    near: 12.0
    mid: 24.0
    far: 48.0

生物定义 model: 节 ​

yaml
model:
  blueprint: "bone_lord"        # 必填：模型蓝图名
  api: "model_engine"           # 当前版本解析但未生效：后端仍按全局 config.yml 的 model.api 选择
  scale: 1.2                    # 可选：模型缩放，默认 1.0
  animations:                   # 可选：标准动作 → 引擎动画名映射
    idle: "breath"
    walk: "walk_slow"
    run: "run_fast"
    death: "die"
    hurt: "flinch"
    attack: "swing"
    skill: "cast"
    interact: "nod"
  keyframes:                    # 可选：为任意动画定义 K帧时间轴
    attack:
      duration_ticks: 24        # 时间轴总长（tick）
      loop: false               # 是否循环
      priority: "action"        # ambient|utility|action|reactive|terminal
      conflict: "replace"       # replace|reject 同优先级冲突策略
      frames:
        - tick: 0
          action: "self | play_sound sound=minecraft:entity.wither.shoot"
        - tick: 10
          label: "impact"
          action: "self | spawn_particle particle=flame"
  lod:                          # 当前版本解析但未生效：LOD 档位仍按全局 config.yml 的 model.lod 判定
    near: 12.0
    mid: 24.0
    far: 40.0
字段类型必填默认值取值范围说明
blueprintstring是（该节内）无后端 blueprints/ 中的蓝图名缺失或空白时整节被忽略并打加载告警（console.model_missing_blueprint）。运行时若后端找不到该蓝图，会打 console.model_blueprint_missing 告警并跳过挂载。
apistring否无auto / model_engine / better_model解析但不消费：模型桥仍由全局 config.yml 的 model.api 创建。
scaledouble否1.0—模型缩放倍率，挂载与 mob_set_model 热切换时都会使用。
animations.<动作键>string否无（使用内置默认动画名）后端蓝图中存在的动画名动作键 → 引擎动画名映射。键名与值都会被规范化（键转小写、值去空白）；空白值被忽略。
keyframes.<动作键>section否无—K帧时间轴；键名即动作键（规范化小写）。非标准动作键（不在 idle…interact 之内）会以 utility 优先级、不循环注册。
keyframes.<动作键>.duration_ticksint否20≥ 1时间轴总长（tick）。小于 1 时整条时间轴被丢弃并打告警；循环动画以该值作为环绕点。
keyframes.<动作键>.loopboolean否标准动作取该动作的内置值（idle/walk/run 为 true，其余为 false）；非标准动作键为 falsetrue / false是否循环播放。
keyframes.<动作键>.prioritystring否标准动作取该动作的内置优先级；非标准动作键为 utilityambient / utility / action / reactive / terminal（大小写不敏感）播放优先级；无法识别的取值按 ambient 处理。
keyframes.<动作键>.conflictstring否replacereplace / reject（大小写不敏感）同优先级冲突策略；无法识别的取值按 replace 处理。
keyframes.<动作键>.frameslist否[]元素为 {tick, action, label} 映射帧列表。帧按列表顺序执行，不排序；缺 tick 或 tick 不是数字的帧被丢弃并打告警（loader.model_keyframe_missing_tick）。
keyframes.<动作键>.frames[].tickint是（帧内）无≥ 0（tick）触发 tick；tick: 0 在动画开始时立即执行。不会被截断到 duration_ticks 内——若某帧的 tick 大于时长，播放会延后到该 tick 才继续/收尾。
keyframes.<动作键>.frames[].actionstring否""一行 CoreLib 动作管道帧载荷；空串的帧只通知监听者、不执行动作，编译失败会在控制台打告警。
keyframes.<动作键>.frames[].labelstring否""—帧标签，随帧通知传给动画监听者（诊断用）。
lod.near / lod.mid / lod.fardouble否16.0 / 32.0 / 48.0—解析但不消费：LOD 档位由全局 config.yml 的 model.lod 判定。
  • model: 节可整体缺省；缺省则该生物不挂载模型。
  • model.api 与 model.lod 会被解析，但当前版本没有任何消费点：模型桥由全局 config.yml 的 model.api 创建，LOD 档位也由全局 model.lod 判定。写在这里不会改变行为，请改全局配置。

标准动作 ​

动作触发时机默认优先级循环
idle挂载后 / 瞬时动作播完回落 / 静止ambient是
walk水平速度 ≥ walk_speed_thresholdambient是
run水平速度 ≥ run_speed_thresholdambient是
attack攻击命中（on_damage_give）action否
skill技能释放（经 mob_play_animation 触发）action否
interact交互（经 mob_play_animation 触发）utility否
hurt受伤（on_damage_take）reactive否
death死亡（on_death），播完后延迟卸载terminal否

优先级规则：高优先级动作抢占当前播放；同优先级按 conflict 策略替换或拒绝；低优先级请求被拒绝。terminal（death）不可被抢占。未定义时间轴的标准动作使用默认时长（20 tick）与该动作的内置优先级/循环设置。

关键帧（K帧） ​

K帧时间轴由 EmakiCoreLib 的动画调度器驱动：动画开始播放时，tick: 0 的帧立即执行，后续帧在对应 tick 于实体所属线程精确触发。帧载荷是一行 CoreLib 动作管道（spawn_particle、play_sound、属性修改、状态切换等任意已注册段落均可书写），因此动作组合与表达式占位符直接复用全系管道语法。

动作段 ​

在任意 CoreLib 动作行中（技能、掉落动作、第三方插件）可书写：

text
self | mob_play_animation animation=spin
self | mob_stop_animation animation=spin
self | mob_set_model blueprint=bone_lord_phase2
段落参数类型必填默认值说明
mob_play_animationanimationstring是无生物 model.animations / model.keyframes 中定义的动作键；缺失或空白按配置错误返回。
mob_stop_animationanimationstring是无同上；停止对应定义的播放。
mob_set_modelblueprintstring是无新蓝图名；缺失或空白按配置错误返回，后端找不到该蓝图时打告警并保持原模型。
  • 三个段落都要求目标解析为受管生物实体；非受管生物返回 skipped、不报错。
  • mob_set_model 热切换蓝图（沿用该生物定义的 scale），切换后自动回到 idle。

第三方插件扩展 ​

其他插件可经 EmakiCoreLibApi 注册自定义动画定义、播放与监听（见 CoreLib 动画系统）。EmakiMobs 的动画调度同样消费该注册表，因此第三方注册的 mob:<id>:<key> 定义可被 mob_play_animation 直接引用。

故障排查 ​

现象检查
生物无模型后端插件是否安装；model.api 是否指向已安装后端；启动日志是否出现 No usable model backend found（auto 且两个后端都不可用）或 Model backend '<名称>' is not installed。
蓝图缺失告警是否出现 console.model_blueprint_missing；蓝图名是否与后端 blueprints/ 内文件名（去后缀）一致；后端是否已 /meg reload 或重启。
动画不播放引擎动画名是否存在于蓝图中；animations: 映射是否写对动作键。
K帧不触发frames[].action 是否为合法动作行（编译失败会打 Animation keyframe line did not compile 告警）；frames[].tick 是否按升序书写（帧按列表顺序执行，不排序）；tick 是否写成了大于 duration_ticks 的值（不会被截断）。
远距模型消失属 LOD 设计行为；分界点是 lod.mid 而非 lod.far，先调大 lod.mid，再按需调大 lod.far（搜索半径）与 view_distance（仅 ModelEngine 生效）。
