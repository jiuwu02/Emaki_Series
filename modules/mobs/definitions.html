生物定义 ​

生物定义文件位于 plugins/EmakiMobs/mobs/*.yml，每个文件对应一种自定义生物。目录下所有 .yml 都会被加载；单个文件解析失败只影响该文件（记录 issue），其余文件继续加载。首次启动释放的默认定义是 mobs/example_zombie.yml（受 release_default_data 控制）；下例与插件内置的 mobs/elite_zombie.yml 同形。

顶层字段 ​

字段类型必填默认值取值范围说明
idstring是无非空白字符串生物唯一 ID。为空或缺失时该文件被记录 issue 并丢弃。若与原版 EntityType 名称完全一致（大小写不敏感），自动启用类型覆写。命令与 API 均按该值区分大小写匹配。
typestring否与 id 相同合法原版 EntityType 名（如 zombie、skeleton、creeper，大小写不敏感）底层原版实体类型；无法解析时该文件被记录 issue 并丢弃。
display_namestring否null任意字符串仅作为定义元数据暴露给 API（MobDefinition.displayName()），不会自动设置为实体名牌，也不出现在命令输出中。要在游戏内显示名称，请用 components.custom_name。
experienceint否0—击杀掉落经验覆盖值；大于 0 时覆盖原版经验。
componentssection否空键名须在组件参考列表内映射到实体属性/数据组件。未知键被静默跳过。
ea_attributessection否空值为数字；键名对应 EA 属性 IDEmakiAttribute 属性映射。仅在安装 EmakiAttribute 时生效，未安装时整节被忽略且不影响其他功能。旧键 attributes 作为兼容回退读取并打 WARN，建议迁移。
actionssection否空值为动作行字符串列表；键为触发器名触发器 → CoreLib 动作行。由 CoreLib 动作管道执行，不需要安装 EmakiSkills。空列表会被忽略；旧键 skills 作为兼容回退读取并打 WARN，建议迁移。详见技能触发器。
threatsection否无见下表威胁仇恨表配置；整节缺省时不启用威胁系统（也不影响 target_selector）。
boss_barsection否无见下表Boss 血条配置；整节缺省时不注册血条。
modelsection否无子键：blueprint（必填）、api、scale、animations.<动作>、keyframes.<动作>.{duration_ticks,loop,priority,conflict,frames[]}、lod.{near,mid,far}模型挂载与动画；字段与默认值见实体模型与动画的「生物定义 model: 节」。缺 blueprint 时整节被忽略并打加载告警。
target_selectorstring否nulltarget_selectors.yml 中已定义的 selectors id目标选择器 id（读取时规范化为小写）。设置后生物按该选择器挑选目标，优先于威胁表；未设置时走威胁表逻辑。id 不存在时选择失败、不改变目标。
lock_targetsection否无（按未启用处理）enabled、interval_ticks目标锁定配置。仅在同时设置了 target_selector 且 enabled: true 时生效：按 interval_ticks 周期重选目标并写入实体目标。

类型覆写 ​

当 id 与一个有效的原版 EntityType 名称完全一致时（大小写不敏感），EmakiMobs 会在 CreatureSpawnEvent 上给该实体打上受管标记，并对其应用本定义的 components（含把 max_health 补满）。标记完成后，ea_attributes 也会通过 EA 贡献提供方作用到该实体，因为该标记就是属性贡献的判据。

yaml
# 对所有原版僵尸应用加强属性
id: zombie
type: zombie
components:
  max_health: 22.0
  attack_damage: 3.5

类型覆写不会触发 EmakiMobSpawnEvent，也不会执行 on_spawn 动作行（两者只属于经生物工厂创建的实体）。此外它不读取 spawn_rules/，因此不受刷新规则约束。

CAUTION

⚠ 类型覆写会影响服务器上所有自然刷新的该类型生物，包括其他插件产生的同类型生物。如只需特定区域的自定义生物，使用独立 id 配合 spawn_rules/ 中 type: natural 规则。

ea_attributes 字段（可选） ​

yaml
ea_attributes:
  STR: 15      # 键名与 EmakiAttribute 中定义的属性 ID 一致
  VIT: 10
  AGI: 5

本节完全可选：只有安装了 EmakiAttribute 插件时才会生效。未安装 EmakiAttribute 时，EmakiMobs 会忽略整个 ea_attributes 节，不报错、不影响生物定义的其他部分。

字段类型必填默认值取值范围说明
<属性 ID>double否无数值；绝对值 ≤ 1e-9 的条目被跳过以属性 ID 为键、数值为值。仅读取数字类型，非数字值会被静默忽略。

资源类属性对怪物无效

health / mana 一类 RESOURCE 型属性的当前值权威是玩家侧资源系统，对非玩家实体不产生效果。要抬高怪物血量上限请用 components.max_health，或使用 VANILLA 映射属性（如 max_health_vanilla）。同时在 components.max_health 与 ea_attributes.max_health_vanilla 中配置同一概念会触发预检 WARN，提示两者会叠加。

threat 字段 ​

字段类型必填默认值取值范围说明
enabledboolean否truetrue / false是否启用威胁系统。false 时不累计威胁，也不改写目标。
max_rangedouble否64.0—（格）威胁驱逐距离。玩家可以在超距时继续累计威胁（例如远程攻击），但下一个衰减周期（每 20 tick 一次）会按该距离把越界玩家移出威胁表。
weights.damagedouble否1.0—玩家对该生物造成伤害时，每点伤害累加的威胁值。
weights.healingdouble否0.5—玩家每次回血（含自然回血）时，按治疗量乘以该权重，累加到其 32 格内的受管生物威胁表中。
decay.ratedouble否0.05—每个衰减周期（20 tick）把威胁值乘以 1 - rate；0.05 约等于每秒衰减 5%。
decay.out_of_rangeboolean否truetrue / false是否按 max_range 驱逐越界玩家。整节 decay 缺省时按 true 处理。

威胁值低于 0.001 的条目会被清理；选出最高威胁目标时要求威胁值严格大于 0，因此威胁被衰减到接近 0 时该生物不会重新选定目标（可能表现为不再主动追人）。

boss_bar 字段 ​

字段类型必填默认值取值范围说明
titlestring否""任意字符串血条标题，支持 MiniMessage 格式。
colorstring否PURPLEPINK / BLUE / RED / GREEN / YELLOW / PURPLE / WHITE（大小写不敏感）血条颜色；非法取值静默回退 PURPLE。
stylestring否SOLIDSOLID / SEGMENTED_6 / SEGMENTED_10 / SEGMENTED_12 / SEGMENTED_20（大小写不敏感）血条风格；非法取值静默回退 SOLID。
rangedouble否64.0—（格）可见范围。每 20 tick 重算一次观众集合：同世界且距离不超过该值的在线玩家可见，其余被移出。进度条在受伤与回血事件后更新。

非法取值会静默回退

color 与 style 用 valueOf 解析，解析失败时不报错、不打日志，直接回退到默认值（color → PURPLE，style → SOLID）。

BarStyle 没有 NOTCHED_6 / NOTCHED_10 / NOTCHED_12 / NOTCHED_20 这类取值。写成 NOTCHED_10 不会有任何提示，血条会静默变成实心（SOLID）。分段血条只能用 SEGMENTED_*。

lock_target 字段 ​

字段类型必填默认值取值范围说明
enabledboolean否falsetrue / false是否启用周期锁定。仅在同时设置了 target_selector 时参与锁定。
interval_ticksint否20—（tick）重选周期。锁定循环本身每 20 tick 跑一次，配置值会向上取整到 20 tick 的倍数（< 20 按一轮处理）。

目标选择器（target_selectors.yml） ​

target_selectors.yml 是插件静态文件（只在缺失时释放，升级不合并覆盖），为所有生物共用。生物定义用 target_selector 引用其中 selectors 下的 id。

字段类型必填默认值取值范围说明
snapshot_interval_ticksint否20≥ 0；0 = 关闭快照玩家打分快照的调度间隔（tick）。关闭后 equipment、expression、health 恒为 0，配置了 filter 的选择器没有合格候选。
snapshot_players_per_tickint否20≥ 1每轮最多派发多少名在线玩家到其所属线程重算；超出的玩家顺延到后续轮次。
equipment_tables.<表 id>section否空—装备权重表集合，供 score.type: equipment 引用。
equipment_tables.<表 id>.slotsstring list否[]槽位名：head / chest / legs / feet / main_hand / off_hand（另接受 mainhand / offhand）；其他值按 EquipmentSlot 枚举名解析参与评分的装备槽位；无法识别的槽位打 WARN 并跳过。
equipment_tables.<表 id>.default_weightdouble否0—表内未列出的物品的默认权重。
equipment_tables.<表 id>.weights.<物品源>double否无物品源简写，如 minecraft:iron_sword 或 emakiitem:<id>物品 → 权重。无法解析或物品源不可用的条目打 WARN 并跳过。
selectors.<选择器 id>section否空—选择器定义集合。整节缺失视为阻塞性配置错误（预检 ERROR）。该 id 读取时规范化为小写，供 target_selector 引用。
selectors.<选择器 id>.modestring否highesthighest / lowest / random / weighted_random / first_damager / last_damager（大小写不敏感）目标挑选方式；非法取值打 WARN 并丢弃该选择器。highest/lowest/weighted_random 在 score 为空时选不出目标。
selectors.<选择器 id>.rangedouble否未设置≥ 0（格）候选玩家搜索半径。缺省时依次回退到该生物的 threat.max_range，再回退到 16。
selectors.<选择器 id>.filtersection否无CoreLib 条件块候选过滤条件；以玩家为上下文按快照逐玩家求值，未通过者不进入候选。
selectors.<选择器 id>.scorelist否[]步项 type：threat / distance / health / equipment / expression打分项列表；总分是各步项「取值 × factor」之和。未知 type 或非有限 factor 打 WARN 并跳过该步项。
selectors.<选择器 id>.score[].factordouble否1.0有限数值该步项的权重系数。
selectors.<选择器 id>.score[].tablestringtype: equipment 时是无已定义的装备表 id引用的装备权重表；不存在时打 WARN 并跳过该步项。
selectors.<选择器 id>.score[].valuestringtype: expression 时是无长度 ≤ 256、括号嵌套 ≤ 10 层、不含 `/$/\表达式串（如 %vault_eco_balance% / 1000）；校验失败打 WARN 并跳过该步项。

NOTE

filter 与 score 的条件/表达式语法由 EmakiCoreLib 提供，见 CoreLib 条件与表达式。快照关闭（snapshot_interval_ticks: 0）时基于快照的步项恒为 0。

完整示例 ​

yaml
id: elite_zombie
type: zombie
display_name: "<gradient:#ff4444:#ffaa00>精英僵尸</gradient>"

components:
  max_health: 80.0
  movement_speed: 0.28
  attack_damage: 7.0
  follow_range: 40.0
  knockback_resistance: 0.3
  custom_name: "<gradient:#ff4444:#ffaa00>精英僵尸</gradient>"
  custom_name_visible: true
  persistent: true
  loot_table: "emakimobs:entities/elite_zombie"

experience: 80

ea_attributes:
  STR: 15
  VIT: 10

actions:
  on_spawn:
    - "nearby radius=20 include_players=true | send_message text='<red>精英僵尸降临！'"
  on_death:
    - "killer | give_exp amount=80"

threat:
  enabled: true
  max_range: 48.0

boss_bar:
  title: "<gradient:#ff4444:#ffaa00>精英僵尸</gradient>"
  color: RED
  style: SEGMENTED_10
  range: 60.0

loot_table 同时是 YAML 掉落表的开关

示例中的 loot_table 值会交给 Bukkit 的掉落表注册表查询原版/数据包表，插件不注册数据包，因此这个命名空间值通常查不到；它「能用」是因为 YAML 掉落表的启用只判断该键是否存在。反之，写 loot_table: "minecraft:entities/zombie" 会设置原版掉落表，但只要同时存在 loot_tables/elite_zombie.yml，死亡时就会清空全部原版掉落（经验仍保留）。详见组件参考的「掉落类字段」。
