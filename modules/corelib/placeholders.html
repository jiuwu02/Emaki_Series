占位符参考 ​

CoreLib 在 Action 里能直接使用的内置变量和内联 Token 如下, 附使用示例

前置说明: CoreLib 不注册 PlaceholderAPI 扩展, 动作上下文变量由它自己提供, 所有模块执行 Action 时都能用

动作上下文变量 ​

Action 触发时, CoreLib 会自动把这些内置变量注入上下文. 任何模块的 Action 配置里都能用 %variable% 写法引用:

内置变量 ​

变量说明示例
%player%玩家名Steve
%player_name%玩家名 (和 %player% 一样)Steve
%player_uuid%玩家的 UUID550e8400-e29b-...
%player_world%玩家所在世界的名字world
%player_x%玩家的 X 坐标 (浮点数)128.5
%player_y%玩家的 Y 坐标 (浮点数)64.0
%player_z%玩家的 Z 坐标 (浮点数)256.0
%phase%当前动作阶段success

注意: 上面这些玩家变量只在动作上下文里有玩家时才会注入. 变量名匹配不区分大小写; 调用方已经注入同名变量时, 以调用方给的值为准

使用示例 ​

yaml
actions:
  - 'send_message text="<green>恭喜 %player_name%，操作成功！</green>"'
  - 'run_command_as_console command="say %player_name% 在 %player_world% 完成了操作"'

内联 Token ​

CoreLib 还支持 <show_item> 内联 Token (写进文本即被替换的特殊标记). Action 上下文里设了 show_item 后, 聊天消息会显示物品悬浮提示, 可直接观察验证

yaml
actions:
  - 'send_message text="你获得了 <show_item>！"'

说明 ​

  • 各子模块 (Forge, Gem, Skills 等) 会在自己的 Action 上下文里注入额外变量, 详见各模块的占位符文档
  • 动作上下文变量和 PlaceholderAPI 占位符是两套独立的系统, 格式一样但解析时机不同
  • PlaceholderAPI 占位符在 Action 里同样能用 (需要装 PlaceholderAPI)
