段 ID 表 ​

动作管道里全部段的 ID 与用途如下, 按名字就能定位

动作管道共有 218 个段, 分三类: source (目标源)29 个, gate (筛选/控制类段)17 个, action (动作)172 个. 其中 131 个是 CoreLib 内置段 (source 25 / gate 16 / action 90), 另外 87 个由本仓库的附属插件注册进同一套注册表: EmakiAttribute, EmakiCodex, EmakiCooking, EmakiForge, EmakiGem, EmakiItem, EmakiLevel, EmakiMobs, EmakiSkills, EmakiStrengthen, EmakiStorage

每行末尾的来源列写明这个段是谁注册的. 来源是 CoreLib 的是内置段, 点它的 ID 跳到动作系统 对应段的详情节, 那里给出该段的全部专属参数 (参数名, 数据类型, 取值范围, 默认值, 作用说明); 来源是插件名的是该插件注册的段, 点它的 ID 跳到那个插件自己的 CoreLib 动作页, 它的参数, 上下文变量与执行时机以那一页为准. EmakiMobs 暂时没有单独的动作页, 它的 8 个段只列 ID 与用途. 三类段通用的控制项与书写规范见动作系统的公共参数 (所有段通用)

怎么用: 先点下方按钮按分类筛选, 再用输入框按段 ID, 用途文字与来源插件实时检索 (支持任意片段匹配, 中英文皆可, 如输入 teleport, 玩家 或 EmakiLevel). 列表在页面加载时即完整输出, 不依赖脚本执行
