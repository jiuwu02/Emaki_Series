段 ID 表 ​

动作管道内置段共 131 个, 分三类: source (目标源)25 个, gate (闸门)16 个, action (动作)90 个. 本页只列每个段的 ID 与用途; 点击任意 ID 可直接跳到动作系统对应段的详情节, 那里给出该段的全部专属参数 (参数名, 数据类型, 取值范围, 默认值, 作用说明). 三类段通用的控制装饰器与书写规范见动作系统的公共参数 (所有段通用)

用法: 下方按钮按分类筛选; 输入框同时按段 ID 与用途文字实时检索 (支持任意片段匹配, 中英文皆可, 如输入 teleport 或 玩家). 列表在页面加载时即完整输出, 不依赖脚本执行
