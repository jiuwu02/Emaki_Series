命令与权限 ​

主命令是 /emakistructure, 你也可以简写成 /ems 或 /estruct. 直接输入主命令不带子命令时, 会输出用法提示; 如果输入了不认识的子命令, 提示里会告诉你用 /ems help 查看全部命令

命令列表 ​

命令需要权限说明
/ems help无 (所有人都能用)列出所有命令
/ems get <模板> [朝向]emakistructure.use在你面前 3 格处临时摆出这个模板, 只为看效果 (不会写盘, 不会记进回滚日志)
/ems select pos1 / pos2emakistructure.edit把你当前站的位置记为选区的第一个 / 第二个角点. 两个点必须在同一个世界, 否则会提示
/ems select adjust <add|reduce> <front|back|left|right|up|down> <数值>emakistructure.edit沿指定方向把选区扩大或缩小; 缩小过头会提示"收缩过多"
/ems select clearemakistructure.edit取消当前选区与线框
/ems structure export <名称> [entities]emakistructure.edit把当前选区导出成结构模板 structures/<名称>.nbt (原版 .nbt 结构文件, 不是多方块定义); 默认不保存选区内的生物, 需要保存时在末尾加上 entities
/ems structure place <模板> <朝向>emakistructure.edit在你站的位置放置这个结构模板; 朝向见下文. 多方块请改用 /ems multiblock place
/ems multiblock export <id> [force]emakistructure.edit按选区把机关布局记录成 multiblocks/<id>.yml (只记录, 不会放置). 该 id 已存在时要加 force 才会覆盖
/ems multiblock place <id> [朝向]emakistructure.edit在你站的位置摆出这个多方块机关: 原版方块, 自定义方块与家具都会按朝向摆放, 放完自动开始形状检测
/ems multiblock listemakistructure.admin列出所有已加载的多方块定义, 以及成员数, 是否允许旋转, 进行中与已完成的数量
/ems multiblock validate <id>emakistructure.admin对现场形状再检查一次, 并列出成员数, 无法识别的自定义方块, 缺失的家具来源与实例数量
/ems reloademakistructure.reload重新读取配置, 语言文件, 模板缓存与生物点位 / 家具缓存, 并显示已加载的模板数量
/ems debug ...emakistructure.admin转交给 CoreLib 的调试命令, 只输出 structure 模块的日志, 用于排查问题

朝向参数 ​

get, structure place, multiblock place 的 [朝向] 共 8 个可选值:

取值含义
north / east / south / west只旋转, 不镜像
north_mirror / east_mirror / south_mirror / west_mirror旋转之后再做左右镜像

不填朝向时, 插件按你当前面朝的方向自动取最近的一个 (东南西北之一). 填了不认识的值时, 提示里会列出可用值

权限节点 ​

权限在 paper-plugin.yml 中声明, 默认值如下:

权限默认值说明
emakistructure.usetrue (所有玩家)使用预览命令 get
emakistructure.editop框选, 结构导出与放置, 多方块导出与放置
emakistructure.reloadop重载配置
emakistructure.adminop管理与排查: multiblock list / validate, debug; 已包含上面全部子权限

按 Tab 键自动补全时, 插件会按你的权限过滤子命令, 并补全模板名, 多方块 id, 朝向值, 以及 adjust 的方向和 select 的操作名; 你没有的权限对应的子命令不会出现

使用示例 ​

# 框选一个 12×8×12 的区域
/ems select pos1
/ems select pos2
/ems select adjust add up 3

# 导出为结构模板并就地预览
/ems structure export village_hub_a
/ems get village_hub_a north

# 朝南放置
/ems structure place village_hub_a south

# 记录一个多方块结构 (按选区)
/ems multiblock export teleporter
/ems multiblock place teleporter east

# 查看已加载的多方块定义与状态
/ems multiblock list
/ems multiblock validate teleporter

# 重载
/ems reload

CAUTION

structure export 导出的是原版 .nbt 结构文件 (存放在 structures/ 目录), multiblock export 导出的是自己的多方块布局定义 (存放在 multiblocks/ 目录). 两者是两种不同的文件, 不能互相替换使用, 放置时也不能混用命令
