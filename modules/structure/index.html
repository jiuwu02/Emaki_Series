EmakiStructure ​

EmakiStructure 是结构生成与多方块结构交互模块. 它允许服主框选区域导出 .nbt 结构模板并按朝向放置, 记录并触发多方块结构定义, 在生成中断时事务回滚, 拦截替换尚未生成区块中的原版结构, 还支持从 ItemsAdder / Oraxen / Nexo / CraftEngine 四源识别与还原家具

基本信息 ​

项目值
模块版本1.0.4
构建产物EmakiStructure-1.0.4.jar
API 坐标emaki.jiuwu.craft:emaki-structure-api:1.0.1 (仅 compileOnly, 不放入 plugins/)
主命令/emakistructure (别名 /ems, /estruct)
硬依赖EmakiCoreLib (required: true)
软依赖MythicMobs, EmakiMobs, ItemsAdder, Oraxen, Nexo, CraftEngine (均为 required: false, 缺失时对应能力降级)
权限节点emakistructure.use, emakistructure.edit, emakistructure.reload, emakistructure.admin
描述符基线api-version: "1.21.8", folia-supported: true

NOTE

EmakiStructure 是 .key 门控的私有模块: 仓库根存在 .key 文件时才参与默认构建

页面内容

核心能力 ​

能力说明
两点框选/ems select pos1/pos2 设点, adjust 微调, clear 清除; 选区以发光 BlockDisplay 连续线框高亮 (受视距与世界边界约束)
结构模板选区导出为 structures/<名称>.nbt, 按朝向 (含镜像) 放置; 导入时逐项校验体积, 调色板与方块实体载荷
生成护栏每 tick 写入限额, TPS 自适应限流, 队列超时, 支撑面策略 (skip/keep/fill), 玩家被困检测
事务回滚生成中断 (reload / 停服 / 超时 / 超限) 时按 delta 快照回滚到生成前状态, 启动期自动清理未提交事务
原版结构拦截替换对尚未生成的区块按 replace_rules 用自备模板替换原版结构 (如村庄), 已生成区块永不改写
多方块结构按选区导出 multiblocks/<id>.yml, 玩家交互满足形状时触发配置动作; 支持形状校验, 冷却, 条件与增量检测
家具四源导出时识别 ItemsAdder / Oraxen / Nexo / CraftEngine 家具写入 furniture/<模板>.yml 侧车, 放置时按朝向还原, 回滚时移除
结构内生物spawns/<模板>.yml 侧车在结构生成时按点位/球体/区域生成生物 (含 minecraft:/mythicmobs:/emakimobs: 前缀)

默认配置目录 ​

text
plugins/EmakiStructure/
├── config.yml
├── structures/           ← .nbt 结构模板 (structure export 产物)
├── multiblocks/          ← 多方块定义 (multiblock export 产物)
├── spawns/               ← 结构内生物点位侧车
├── furniture/            ← 家具还原侧车 (导出结构时生成)
├── journal/              ← 生成事务回滚日志 (运行期文件)
├── replaced/             ← 原版结构替换 marker (运行期文件)
└── lang/

structures/ 与 multiblocks/ 由游戏内命令导出生成, 也可手工放入; spawns/, furniture/ 手工编写; journal/ 与 replaced/ 是运行期文件, 不要手工编辑. 文件保存后执行 /ems reload 生效

典型工作流 ​

  1. /ems select pos1 / pos2 框选区域, 确认选区尺寸
  2. /ems structure export <名称> 导出为 structures/<名称>.nbt
  3. (可选) 为该模板编写 spawns/<名称>.yml 生成生物点位; 结构含家具插件方块时家具侧车随导出生成
  4. /ems get <名称> [朝向] 就地预览, 或 /ems structure place <名称> <朝向> 正式放置
  5. 多方块: /ems multiblock export <id> 按选区记录布局, 玩家凑齐形状后自动触发动作
  6. 出现原版结构替换需求时在 config.yml 的 replace_rules 中声明规则

与其他模块的关系 ​

模块协作方式
EmakiCoreLib硬依赖: 调度器, 调试命令, 消息与配置预检基础设施; 多方块触发动作走 CoreLib 动作管道
EmakiMobs / MythicMobsspawns/ 侧车可生成 emakimobs: / mythicmobs: 前缀的自定义生物 (均为可选依赖)
ItemsAdder / Oraxen / Nexo / CraftEngine家具与自定义方块的可选来源, 缺失时对应家具条目跳过并告警
