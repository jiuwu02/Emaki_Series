结构模板 ​

结构模板是原版 .nbt 结构文件, 存放在 plugins/EmakiStructure/structures/<名称>.nbt. 模板是生成 (place), 预览 (get) 与原版结构替换 (replace_rules) 的共同载体

选区与高亮 ​

  • 两点框选: /ems select pos1, /ems select pos2 设置当前站位; 两点必须同世界
  • 选区就绪后回显坐标与尺寸 (X × Y × Z), 并以发光 BlockDisplay 实体拼出连续线框 (12 条棱 + 顶角标记), 线框在视距内可见, 离开世界或超时后销毁
  • select adjust 按方向微调; select clear 清除选区与高亮
  • 选区会话空闲超时时长由 selection.session_timeout (默认 30m) 控制, 超时自动销毁高亮并释放会话
  • 选区尺寸受 generate.size_limit 限制, 超限拒绝 (error.selection.too_large)

导出校验 ​

/ems structure export <名称> 写盘前逐项校验, 任一不通过即拒绝并给出原因:

校验对应报错键
名称仅允许小写字母, 数字, 下划线, 连字符, 字母或数字开头, 长度 ≤ 64error.name.invalid
选区不超 generate.size_limit 与导出上限error.export.too_large
选区内至少有 1 个可导出方块error.export.no_blocks
单文件字节 ≤ template.import_max_file_bytes (默认 32 MiB)error.template.file_too_large
调色板条目 ≤ template.palette_limit (默认 4096)error.template.palette_exceeded
单个方块实体载荷 ≤ template.block_entity_max_bytes (默认 64 KiB)error.template.block_entity_too_large
跨版本无法解析的方块状态按 template.legacy_policy 处理 (reject 拒绝整文件 / skip 跳过并置空气)error.template.legacy_block_rejected, console.template_legacy_skipped

导出成功回显方块数, 尺寸, 家具条目数 (越界跳过数) 与文件路径. 导出为单次写入, 不使用临时文件中转

放置 ​

/ems structure place <模板> <朝向> 的生成链路:

  1. 模板与尺寸检查: 模板不存在报 error.template.not_found, 尺寸超 generate.size_limit 报 error.generate.rejected_by_limit
  2. 事务日志: 创建 journal/ 快照日志, 失败则拒绝生成 (error.generate.journal_failed)
  3. 支撑面检查: 按 generate.ground_mode 判定 (见配置详解), 不通过报 error.generate.ground_unsupported 并放弃
  4. 排队写入: 按 generate.max_blocks_per_tick 分 tick 写入, 受队列超时 (generate.queue_timeout) 与 TPS 自适应限流约束; 超时中止 (error.generate.queue_timeout) 并回滚
  5. 实体与生物: 按 generate.entity_policy 处理模板内实体, 并执行 spawns/ 侧车的生物点位
  6. 结算: 成功回显位置, 朝向与覆盖方块数; 玩家被困时给出离开提示 (error.generate.player_trapped)

生成期间的 reload / 停服由事务回滚恢复: 启动时若发现未提交 journal, 会先执行回滚并暂停生成能力, 回滚完成后再放行 (console.rollback_recovering / console.rollback_recovered). 回滚未完全成功的事务会改名为 rollback-partial 标记并不再自动重试, 可用 /ems debug 查看

/ems get <模板> [朝向] 为面前 3 格处的预览生成, 用于试放观察位置与朝向

生物点位侧车 ​

spawns/<模板名>.yml:

yaml
version: 1
enabled: true
spawns:
  - type: "minecraft:skeleton"
    pos: [4, 1, 4]            # 固定点位, 须在模板尺寸内
    count: 2                  # 1-16
    chance: 1.0               # 0.0-1.0
    facing: "north"           # north/south/east/west, 可省略
    level: 5                  # 可省略 (等级型插件使用)
  - type: "emakimobs:elite_zombie"
    region:                   # 区域随机点位, min ≤ max 且在尺寸内
      min: [0, 1, 0]
      max: [15, 1, 15]
    radius: 0                 # 0-64; >0 时 pos 用球体分布, 球体须完全在模板内
    count: 4
  • type 必须带前缀: minecraft:, mythicmobs:, emakimobs: (后两者需对应插件在场)
  • pos 与 region 必须且只能提供一个
  • 单次生成生物合计 ≤ spawn.max_per_generation (默认 32), 超出拒绝整个侧车文件; 每 tick 批次 ≤ spawn.batch_per_tick (默认 8)
  • 总开关 spawn.enabled: false 时整体忽略, 不加载也不告警

家具侧车 ​

furniture/<模板名>.yml 在导出结构时由四源 (ItemsAdder / Oraxen / Nexo / CraftEngine) 家具识别生成; 选区外的家具会被跳过并计入导出回显的"越界跳过"

yaml
version: 1
enabled: true
furniture:
  - id: "itemsadder:myplugin:chair"   # 前缀限 itemsadder/oraxen/nexo/craftengine
    pos: [3, 1, 5]                    # 须在模板尺寸内
    yaw: 90.0                         # 0.0-360.0
    facing: "east"                    # 由 yaw 推导, 导出时写入

放置时四源家具按朝向落位 (方块成员落位之后, 生物生成之前); 缺失对应家具插件的条目跳过并告警 (console.furniture_source_absent). 回滚时先尝试四源 remove, 失败回退为移除实体. 总开关 furniture.enabled: false 时整体忽略
