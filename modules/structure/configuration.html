配置详解 ​

主配置为 plugins/EmakiStructure/config.yml, 修改后 /ems reload 生效. 未知顶层键会被配置预检报 WARN (config.yml.<键>), 键值非法时按 error.config.invalid 报错并按合法值处理

发货默认值见 EmakiStructure/src/main/resources/config.yml; version 为 1.0.4, 随资源同步维护, 不要手工改

generate 结构生成 ​

字段类型默认值取值范围说明
generate.size_limitlist<int>[128, 128, 128]每项 8–512单轴尺寸上限 [X, Y, Z], 选区与导入模板共用, 超限一律拒绝
generate.max_blocks_per_tickint30001–200000每 tick 全局写入方块数上限, 所有生成任务共享, 超额排队到下一 tick
generate.entity_policystringallall / passive / none模板内实体生成策略: 全部生成 / 过滤敌对与 Boss 类 / 不生成
generate.ground_modestringskipskip / keep / fill落位地形兜底: skip 底面任一列无实心支撑即放弃 (绝不空投); keep 不检查支撑按原地形落位; fill 支撑不足向下以石头延伸至多 16 格, 仍无支撑则放弃
generate.adaptive_throttlingbooleantruetrue / falseTPS 低于阈值时线性下调每 tick 写入限额至四分之一, 触发时只告警一次
generate.queue_timeoutduration60s纯数字 (秒) 或 30s/5m/1h/1d生成任务在队列中的最长滞留时长, 超时中止该次生成

detection 多方块增量检测 ​

字段类型默认值取值范围说明
detection.sweep_intervalduration00 或 ≥ 30s低频兜底巡检间隔; 0 表示关闭, 启用时不得小于 30s. 只扫描"进行中实例"集合, 不做全图遍历
detection.max_cold_checksint2568–4096单次冷命中反推的锚点候选组上限; 重启或 reload 后点击既有结构按此截断, 超出丢弃并记 debug
detection.instance_limitint8≥ 1每定义每玩家"进行中实例"数量上限, 超限淘汰最旧的
detection.instance_ttlduration10m≥ 1m"进行中实例"无变化存活时长, 超时由巡检清理
detection.debounceduration500ms≥ 0, 支持 ms/30s/5m同一区块坐标变更的合并去抖窗口
detection.retrigger_on_reformbooleanfalsetrue / false结构被破坏降级后重新凑齐时是否自动再次触发; false 只恢复活动实例不触发, 防止刷动作

replace_rules 原版结构拦截替换 ​

仅作用于尚未生成的区块, 按声明顺序评估, 第一条命中即生效并短路; 未命中原版结构照常生成. 已生成区块与其中既有结构永不改写

yaml
replace_rules:
  - structure: "minecraft:village_plains"   # 仅匹配 minecraft: 命名空间
    template: "village_hub_a"               # 替换用模板名 (structures/ 下同名 .nbt)
    chance: 0.5                             # 概率 [0.0, 1.0]
    worlds: ["world"]                       # 世界白名单, 缺省/空 = 全部世界
    biomes: ["plains"]                      # 群系白名单, 缺省/空 = 不限群系
    enabled: true                           # false = 该条不参与匹配
    apply_to_existing: false                # 恒为 false, 出现 true 即拒载该条并告警
  • 替换 marker 写入 replaced/<world>.marker 保证幂等; 已替换区块不重复替换
  • 引用的模板不存在时告警并放行原版生成 (console.replace_template_missing)
  • 已知限制: 多块结构 (如村庄) 可能出现尾块残留原版部分

rollback.journal_max_bytesint67108864≥ 1048576单事务 delta 快照字节上限, 超限即中止本次生成并回滚, 绝不留下半生成状态
