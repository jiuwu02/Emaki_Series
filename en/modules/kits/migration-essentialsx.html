Migrating from EssentialsX Kits ​

This page is for server owners moving from EssentialsX kits to EmakiKits. The mapping only covers documented ground (per the EssentialsX site and GitHub README); anything uncertain is marked TBC

Concept mapping ​

EssentialsXEmakiKitsNotes
One kit in kits.ymlOne kit in kits/*.ymlEmakiKits keeps one kit per file; the id comes from the id field, not the file name
Kit item listrewards.fixedEmakiKits rewards use CoreLib item-source shorthands (minecraft-bread and friends), which differ from EssentialsX item syntax and need manual rewriting
delay (seconds) cooldownCyclic kits / max_claims_totalEssentialsX uses second-level cooldowns; EmakiKits approximates with daily / weekly / monthly period keys or a total cap. Second-level cooldowns are not supported (TBC)
delay: -1 one-timemax_claims_total: 1The equivalent one-time kit
Kit permissionThe kit's permission fieldEssentialsX uses essentials.kit.<name> (check the EssentialsX docs); EmakiKits requires permissions to start with emakikits., so rename nodes and update LuckPerms accordingly

EssentialsX has no CDK, choice, invite, or cyclic kit concepts (not seen in the evidence gathered, which does not prove their absence). Those capabilities are net-new after migrating

Command mapping ​

EssentialsXEmakiKits
/kit <name>/ekits claim <kitId>
/kit list/ekits list
(none)/ekits preview <kitId> before claiming
(none)/ekits redeem <kitId> <code> CDK redemption

Data migration ​

  • EmakiKits keeps kit definitions in plugins/EmakiKits/kits/*.yml and runtime data in plugins/EmakiKits/data/store.yml; neither is compatible with EssentialsX kits.yml / userdata
  • No automatic import: rewrite kit definitions manually per the tables above. Player cooldown records from EssentialsX cannot be imported; EmakiKits starts from empty records (preserving "already claimed" state has no tooling, TBC)

Suggested steps ​

  1. Install EmakiCoreLib + EmakiKits on a test server and rewrite each kits.yml entry into a kits/*.yml file (see the concept mapping)
  2. Confirm loading with /ekits check, verify rewards with /ekits preview
  3. Switch permission nodes (replace essentials.kit.* with the matching emakikits.* nodes in LuckPerms) and verify claiming
  4. Only after everything checks out, stop using the EssentialsX kits feature (other EssentialsX features are unaffected)
