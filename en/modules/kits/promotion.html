Promotion messaging and platform copy skeletons ​

This page is the baseline for public release copy. All copy is governed by Verification status: pending items must never be presented as verified. The skeletons below are marked "finalize after live tests" and only go out once the tests pass

Main message: one plugin instead of five ​

One EmakiKits covers five kit needs without installing single-purpose plugins:

Need coveredCapability
Daily / weekly / monthly rewardsdaily / weekly / monthly cyclic kits
CDK redemptioncdk kits (once server-wide / counted per player)
Starter kitsjoin kits (with invite-code binding)
Choice kitschoice kits (inline GUI)
Invite rewardsinvite kits plus the invite leaderboard

Messaging red lines:

  • Sign-in gameplay is not a selling point (EmakiKits explicitly does not do sign-in, see Scope and boundaries); never list sign-in in copy
  • Never write "standalone / no dependencies / lite mode"; disclose the EmakiCoreLib hard dependency honestly
  • Write "pending live tests" for untested capabilities; never write "verified / runs stably". "Not documented" does not mean "absent", and "implemented" does not mean "live-tested"

Platform copy skeletons (finalize after live tests) ​

MineBBS (Chinese) ​

  • One line: A configuration-driven kit module: join, invite, daily, weekly, monthly, CDK, choice, and generic kits in one plugin
  • Points: one kit per YAML file; four reward types (items, money, nested kits, action pipelines); idempotency keys + audit + atomic writes; full in-game GUI editor; random-reward pity; invite leaderboard; Paper 26.1+ and Folia
  • Dependency disclosure: hard dependency on EmakiCoreLib (same family, providing item sources, action pipelines, GUI, and the economy bridge); optional PlaceholderAPI (the %emakikits_invited% placeholder)
  • Version: 1.0.6

SpigotMC (English) ​

  • One line: A configuration-driven kit plugin: join, invite, daily, weekly, monthly, CDK, choice and generic kits in one place
  • Points: one kit per YAML file; four reward types (items, money, nested kits, CoreLib action lines); idempotent claims with audit records and atomic writes; in-game GUI editor; random-reward pity; invite leaderboard with PlaceholderAPI support
  • Dependency disclosure: requires EmakiCoreLib (same ecosystem); PlaceholderAPI optional
  • Format: convert to the channel's BBCode; facts stay identical to the MineBBS entries

Modrinth (Markdown) ​

  • One line: same as SpigotMC
  • Points: same as SpigotMC, as a Markdown list
  • Version and compatibility baseline: 1.0.6, Paper 26.1+ (Folia supported); cite Verification status for test status and never claim untested things
