Stage ID table ​

The action pipeline ships 131 built-in stages across three roles: 25 sources, 16 gates, and 90 actions. This page lists only each stage's ID and purpose. Clicking any ID jumps to that stage's section in Actions, which documents its dedicated parameters (name, data type, allowed range, default, purpose). The control decorators shared by all three roles are covered under Common parameters

How to use: the buttons filter by role; the input box filters by stage ID and purpose text as you type (any substring matches, in either language — try teleport or message). The full list is rendered with the page itself and does not depend on a script running
