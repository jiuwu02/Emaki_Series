Stage ID table ​

Every stage in the action pipeline is listed below with its ID and purpose; search by name and jump straight to the details.

The pipeline has 218 stages in three roles: 29 sources, 17 gates, and 172 actions. Of those, 131 are built into CoreLib (25 source / 16 gate / 90 action), and the other 87 are registered into the same registry by this repository's own plugins: EmakiAttribute, EmakiCodex, EmakiCooking, EmakiForge, EmakiGem, EmakiItem, EmakiLevel, EmakiMobs, EmakiSkills, EmakiStrengthen, EmakiStorage.

The Registered by column at the end of each row says who registered that stage. When the value is CoreLib, the stage is built in: click its ID to jump to that stage's section in Actions, which documents its dedicated parameters (name, data type, allowed range, default, purpose). When the value is a plugin name, click its ID to jump to that plugin's own CoreLib actions page, which is the authority for its parameters, context variables and timing. EmakiMobs has no dedicated actions page yet, so its 8 stages are listed by ID and purpose only. The control decorators shared by all three roles are covered under Common parameters.

How to use: click the buttons to filter by role, then type in the input box to search by stage ID, purpose text and registering plugin at once (any substring matches, in either language — try teleport, 玩家 or EmakiLevel). The full list is rendered with the page itself and does not depend on a script running.
