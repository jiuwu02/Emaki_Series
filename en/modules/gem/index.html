EmakiGem ​

EmakiGem provides equipment sockets, socket openers, gem inlay, extraction, upgrades, gem resonance, gem presentation layers, and optional Attribute output.

Basic information ​

ItemValue
Module version2.8.0
Main command/emakigem
Aliases/egem, /eg
Hard dependencyEmakiCoreLib
Soft dependenciesEmakiItem, EmakiAttribute, PlaceholderAPI
Main permissionsemakigem.use, emakigem.reload, emakigem.admin, emakigem.debug

Main configuration keys ​

Top-level keys in config.yml:

KeyDefaultDescription
version"2.8.0"Configuration structure marker maintained by the resource sync process, not a feature switch.
language"zh_CN"Language file name, resolving to lang/<language>.yml.
release_default_datatrueWhether bundled default data (gems/, items/, resonances/) is released on startup. Setting false stops those three from being restored, but gui/, conditions/, config.yml, and lang/*.yml are unaffected.
socket_openers—Socket opener definitions; see Socket Openers.
inlay_success—Inlay success rate; see Inlay Success Rate.
number_format.default"0.##"Default number format. Falls back to 0.## when the section is missing or the value is blank.
op_bypassfalseWhether OPs bypass cost and condition checks for inlay, socket opening, and extraction.
reroll.session_ttl_seconds120Reroll candidate session lifetime in seconds, minimum 1. On timeout the candidate is discarded and the charge refunded. Changes affect newly generated candidates only.
gui.default_mode"inlay"Default mode for the GUI service. Accepts inlay, upgrade, and open (aliases open_socket, socket_open); an unrecognised value falls back to inlay. Commands still require an explicit mode argument.
gui.save_on_closefalseWhether the current operation state is saved when the view closes.
condition—Global condition group. When absent it is an empty group with type all_of.

NOTE

op_bypass used to live at permission.op_bypass. The legacy key is still read (the top-level key wins), and it is migrated to the top level on startup with a console notice.

WARNING

version has two unrelated version lines; do not mix them. The default resource value in config.yml is 2.8.0. The source additionally holds an internal migration constant CURRENT_VERSION = 2.7.8, used only for configuration migration comparison. The two serve different purposes.
