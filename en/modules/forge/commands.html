Commands and Permissions ​

The main command of EmakiForge is /emakiforge, with /eforge and /ef as aliases. Players use it to open the forge GUI or the recipe book; admins use it to reload configuration, list recipes, and check status

The root command requires emakiforge.use (default true). Additional subcommand permissions are listed below

CommandPermissionDescription
/ef helpRoot permission onlyShow command help. Running the root command with no arguments also shows help
/ef forgeRoot permission onlyOpen the forge GUI. Players only (console senders see the player-only message)
/ef bookemakiforge.book or emakiforge.adminOpen the recipe book. Players only (console senders see the player-only message)
/ef list <type>emakiforge.adminList loaded definitions with display names. Only recipe is implemented (recipes is also accepted) and tab completion only suggests recipe; any other value reports invalid arguments
/ef reloademakiforge.reload or emakiforge.adminReload config, language, GUI templates, and recipes, reporting the reloaded recipe and GUI template counts plus the elapsed time
/ef convert-legacy [confirm]emakiforge.adminMigrates legacy item_sources under materials[], blueprint_requirements[], and result.*.outputs[] in recipes/; material entries keep the legacy key by spec. Without an argument it performs a dry run; confirm (or --apply) writes files and leaves a .bak backup
/ef debug statsemakiforge.debug or emakiforge.adminPrint runtime metrics and the recipe load report (status is equivalent)
/ef debug on / offemakiforge.debug or emakiforge.adminToggle debug output globally
/ef debug player <player>emakiforge.debug or emakiforge.adminTrack debug output for one player
/ef debug module <module>emakiforge.debug or emakiforge.adminEnable debug output for one submodule

Available debug submodules: recipe, forge, gui, pdc. Any other /ef debug argument is handled by the CoreLib debug command

The aliases eforge and ef behave exactly like the root command

Permissions ​

PermissionDefaultDescription
emakiforge.usetrueAllows use of the root command and forge GUI
emakiforge.booktrueAllows opening the recipe book
emakiforge.reloadopAllows reloading configuration
emakiforge.debugopAllows debug output
emakiforge.adminopAllows administrative operations

Which command first ​

SituationRun firstPurpose
A player wants to forge/ef forgeOpen the forge GUI
A player cannot find a recipe/ef bookCheck whether the recipe is loaded
An admin changed recipes or GUI files/ef reloadReload recipes/, gui/, language, and runtime resources
Unsure whether a recipe loaded/ef list recipeInspect the loaded recipe list
Recipe load warnings or errors/ef debug statsInspect runtime metrics and the recipe load report
Unexpected forge results/ef debug module forgeTurn on debug output for the forge submodule

After editing recipes/, gui/, or the language files, run /ef reload; it reports the reloaded recipe and GUI template counts. When debugging a recipe, back up the recipe file you are editing before reloading
