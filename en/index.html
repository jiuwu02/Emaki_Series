Emaki SeriesPaper RPG Plugin Suite

A Paper 26.1+ / Java 25 RPG plugin suite. Install only the modules you need; CoreLib unifies actions, GUI, item sources, PDC data, and presentation rebuilds

Getting Started
Architecture

  • Check CoreLib first

    Every business module depends on CoreLib. Understand item sources, actions, GUI, PDC, expressions, and economy before editing module YAML

  • Put attributes in PDC

    Attribute defines stats, resources, damage types, and conditions. Equipment stats should be written as PDC payloads, not only as lore text

  • Equipment is layered

    Item, Forge, Strengthen, and Gem write separate layers, Accessory adds a standalone accessory panel, and CoreLib rebuilds the final name, lore, attributes, and display state

  • Read progression and production separately

    Level manages multi-type progression. Skills manages triggers and cooldowns. Station manages general crafting and queues. Cooking manages world stations and coordinate state

Emaki Series Documentation ​

Emaki Series is a set of Paper RPG modules you install one by one. Start with CoreLib, which provides the shared action, GUI, item-source, PDC, and presentation systems, then add the business modules you need: attributes, items, forging, strengthening, gems, accessory slots, levels, skills, crafting stations, cooking stations, codex advancements, GUI storage, and custom mobs

Who should read this documentation ​

  • Server owners and configurators: installation order, YAML fields, commands, permissions, and troubleshooting
  • Gameplay designers: equipment growth, materials, strengthening stages, gems, skills, and cooking stations
  • Developers: CoreLib actions, GUI, item source, PDC, assembly layers, and Attribute APIs
  • Maintainers: module boundaries, runtime dependencies, and debugging entry points

Recommended reading path ​

  1. Read Introduction first to decide which modules you need to install
  2. Follow Getting Started to build, install, and verify the plugins
  3. Before writing YAML, read CoreLib for item sources, actions, conditions, expressions, and GUI
  4. For equipment progression, read Attribute → Item → Forge / Strengthen / Gem / Accessory
  5. For progression and gameplay systems, read Level, Skills, Station, Cooking, Codex, and Storage separately. They solve different problems
