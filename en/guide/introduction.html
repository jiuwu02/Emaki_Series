Introduction ​

Emaki Series is a set of RPG plugin modules for Minecraft 26.1+. You install only the modules you need: CoreLib holds the shared infrastructure, and the business modules add attributes, equipment, strengthening, gems, accessories, levels, skills, crafting and cooking stations, the advancement/category codex, GUI storage, and custom mobs

The private-modules gate is the .key marker in the repository root (implemented in settings.gradle, not a Maven profile). When .key exists it adds EmakiSkills, EmakiGem, EmakiItem, EmakiStorage, EmakiStructure, and EmakiAccessory to the build. Without .key, 27 project modules are built; with it, 33 (33/33) :::

Besides the server plugins above, the project also builds one compile-time-only emaki-*-api jar per module. None of them are server plugins, so never put them into plugins/. The emaki.jiuwu.craft.skills.api.pdc package in emaki-skills-api owns the equipment skill PDC codec contract and is shaded and relocated into Item, Forge, Gem, and Strengthen at build time

Why CoreLib exists ​

Most modules need the same infrastructure: actions, GUI sessions, item-source resolution, PDC storage, economy access, expressions, and structured item presentation. CoreLib centralizes those pieces once, so each business module only has to focus on its own gameplay rules

Common module combinations ​

  • Attribute-only combat: install CoreLib + Attribute. Add PlaceholderAPI, MythicMobs, or MMOItems only if you use those integrations
  • Equipment progression: install CoreLib + Attribute + Item + Forge + Strengthen + Gem. Add Accessory for an extra progression line that does not occupy equipment slots
  • Level progression: install CoreLib + Level. Add PlaceholderAPI, MythicMobs, Attribute, Cooking, or Forge when progression needs placeholders, mob drops, attributes, or process rewards
  • Skill system: install CoreLib + Skills + MythicMobs. Add Attribute, Item, or Level when skills need resources, attributes, equipment unlocks, or level requirements
  • Life-skill gameplay: install CoreLib + Cooking. Add Level for cooking/profession exp, and add CraftEngine, ItemsAdder, or Nexo when stations use custom blocks or items
  • Production and warehousing: install CoreLib + Station. Add Storage so the warehouse supplies materials and receives outputs, plus Item or Level for custom results and profession exp
  • Advancement codex: install CoreLib + Codex. Add PacketEvents for advancement tree coordinate injection, and PlaceholderAPI or MythicMobs for their integrations
